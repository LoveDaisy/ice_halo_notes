> 本篇知识点（拟）：$SO(3)\cong\mathbb{RP}^3$（轴角球）、姿态族作为 $SO(3)$ 的子流形（圆、环面）、Haar 测度在坐标下的体积元、纤维丛 $SO(3)\to S^2$ 与它的非平凡性

## 提纲

**本篇回答的问题：我的算法要在 $SO(3)$ 上做积分——这个积分域长什么样，该用什么数值形式去积？**

### 核心洞察

1. **姿态族是 $SO(3)$ 里咬在一起的几块形状。** 片晶是一个圆，柱晶是一张环面，Lowitz 是换了一根体轴的另一张环面；片晶圆就躺在 Lowitz 环面上，Lowitz 摆到 90° 就是 Parry，而 Parry 恰好是两张环面的交线。一张示意图（图 3）就能看出来。
2. **数学上等价的数值表示，好用程度并不相同。** 同一个 $SO(3)$，欧拉角等间距网格在极点处过密，而且越靠近极点越密、在极点发散；族自己的参数、以及「太阳在晶体里的方向 × 绕太阳的转角」这组坐标，体积元不带权。选表示，就是选「体积元长什么样」。

全篇三段：① 立空间（洞察 1 的舞台）→ ② 立洞察 1 → ③ 立洞察 2，并用洞察 1 给出的形状去选坐标。

### ① SO(3) 是什么形状：一个实心球，表面对径粘合（洞察 1 的舞台）

- 角色：给后面所有「形状」一个画布。不讲这一节，②里的「环面」「圆」没有地方画。
- 锚定实例：固定一根转轴，把冰晶从 0° 转到 180°——在「轴角球」里是从球心沿一条半径走到球面；转过 180° 后下一步出现在球面的**对径点**，因为绕 $\mathbf a$ 转 180° 与绕 $-\mathbf a$ 转 180° 是同一个姿态。
- 具体结果：$SO(3)\cong$ 半径 $\pi$ 的实心球 $/$ 边界对径点认同 $\cong\mathbb{RP}^3$。与 ch5「单位四元数在 $S^3$ 上对径认同」是同一件事的两种画法：$S^3$ 的上半球压扁就是这个实心球，赤道上的对径认同就是球面上的对径粘合。本节只给图像，不重推 ch5。
- 数据出处：解析（轴角表示 = $\exp$ 映射，LI `so3.exp` / `so3.log`）；不另设数值核验。
- 图占位：图 1（A 类示意）——实心球、一条过球心的直径、球面上一对对径点用虚线连起来标「同一个姿态」。

### ② 各姿态族在里面占哪块（立洞察 1）

#### ②-1 每一族单独看：圆、环面、整个球（立：形状）

- 角色：先把每一块单独画出来，维数只是副产品。
- 锚定实例与具体结果（理想化族，即 LI / Lumice 各族分布宽度 → 0 的极限；「维数」由参数化的 Jacobian 秩实测）：
  - 随机：整个 $SO(3)$，3 维。
  - 片晶（c 轴竖直）：只剩绕竖直轴转一圈 $R_z(\varphi)$，**一个圆 $S^1$**，1 维。
  - 柱晶（c 轴水平）：c 轴方位 $\psi$ 一个圆 × 绕 c 轴自转 $\theta$ 一个圆 = **环面 $T^2$**，2 维。论证要点：「取 c 轴方向」$R\mapsto R\mathbf e_3$ 把 $SO(3)$ 变成 $S^2$ 上的圆丛；柱晶族是这个丛在赤道圆上的那一截；`column_attitude` $\psi\mapsto R_z(\psi)R_y(90°)$ 本身就是一个全局截面，所以这一截是平凡丛 $S^1\times S^1$，而且映射是单射。数值：36×36 网格（步长 10°）上最近邻测地距离恰为 10°、无重合；0° 与 360° 端点重合（周期）；Jacobian 处处秩 2。
  - Parry（c 轴水平、一个柱面朝上锁死）：柱晶环面上 $\theta$ 固定的一条纬线，**一个圆**，1 维。
  - Lowitz（c 轴绕水平的长对角线摆动）：**2 维，不是 1 维**。它是 $\{R: R\mathbf e_2\ \text{水平}\}$（$\mathbf e_2$ = 六边形顶角方向，即长对角线）——和柱晶族 $\{R: R\mathbf e_3\ \text{水平}\}$ 是同一种环面，只是换了一根体轴；全摆幅时就是整个环面（36×36 网格最近邻同样 10°，单射）。LI / Lumice 的 Lowitz 是 roll 锁 0、c 轴天顶角宽 40° 的高斯：环面上围着片晶圆的一条宽带。
  - 维数小结：片晶 1、Parry 1、柱晶 2、Lowitz 2、随机 3。
- 与前文的关系：ch7 §6 已用「柱晶 2 维、片晶 1 维」推出 $\dim(\text{晕})=\dim Q-\dim\mathrm{Stab}$；本节不重讲那条公式，只补「这 2 维 / 1 维长什么形状」，以及 Parry / Lowitz 两族。
- 数据出处：`code/check_orientation_space.py` [2]（单射性、秩、嵌入）、[3]（各族维数、Lowitz 网格）；族定义取 Lumice `doc/coordinate-convention.md` §1、§5、§7 与 LI `docs/ch11-pose-density-families.md` 族表。
- 图占位：图 2（A 类示意）——柱晶环面，经线标 $\psi$（c 轴方位）、纬线标 $\theta$（自转），画出 Parry 那一条纬线。

#### ②-2 放在一起看：两张环面咬在 Parry 上（立：包含关系，本篇的主图）

- 角色：洞察 1 的主体。前一小节是「零件」，这一小节把零件装起来；ch11 在天空上看到的弧线之间的关系，形状层面的根在这里。
- 锚定实例：Lowitz 的 c 轴从竖直开始绕长对角线往下摆。摆角 0 时它就是片晶；摆到 90° 时 c 轴水平、一个柱面朝上——这就是 Parry。
- 具体结果（全部在原始点集意义下成立，不需要任何对称操作）：
  - **片晶圆 ⊂ Lowitz 环面**：摆角 0 的那一圈。
  - **Parry ⊂ Lowitz 环面**：摆角 90° 的那一圈（roll 锁 0 的口径下逐点相等）。
  - **Parry ⊂ 柱晶环面**：$\theta=180°$ 的那一条纬线（定义）。
  - **柱晶 ∩ Lowitz = Parry**：柱晶环面上一点落在 Lowitz 环面上 ⇔ $(R\mathbf e_2)_z=\sin\theta=0$，与 $\psi$ 无关。LI / Lumice 的 Lowitz（roll 锁 0 的那半张）只交出 Parry 这一圈，没有别的交。
  - 以上全都 ⊂ 随机（平凡）。
  - 所以一条路径就能把四族串起来：**片晶 —(Lowitz 摆动)→ Parry —(绕 c 轴自转)→ 柱晶**，全部躺在随机里。
- 对称性只出现在一句话里（正文一句，数字进附录）：若把 Lowitz 环面取全（摆过 90° 继续摆，roll = 180° 的另一半），它与柱晶还交出第二圈 $\theta=0°$——那是「对面那个柱面朝上」，与 Parry 差一个绕 c 轴 180° 的转动，物理上是同一批姿态；再算上六方柱的另两条长对角线，Lowitz 有 3 张等价的环面，与柱晶共交 6 圈，每一圈都差一个晶体转动对称回到 Parry。所以「商掉晶体对称之后，柱晶 ∩ Lowitz 恰好 = Parry」。
- 数据出处：`code/check_orientation_space.py` [5]（D6 转动群 12 元自检；(a)–(d′) 各条最大误差 $<10^{-15}$ rad 量级）。
- 图占位：**图 3（A 类示意，本篇主图）**——一个代表随机的大球里，两张环面相交于一个圆（Parry，加粗）；Lowitz 环面上另画片晶圆，并用一条「摆角」经线从片晶圆连到 Parry 圆。天空上的像不画（留给 ch11）。

### ③ 要在 SO(3) 上做数值积分，选什么表示（立洞察 2，用洞察 1）

- 角色：本篇的「程序」一半。主线一句话：**几种表示在数学上等价，数值上好用程度不同；差别全在体积元。**
- 区分 ch5 已讲 / 本篇新增：ch5 已讲欧拉角有两个极点奇点、路径过极点数值剧变、四元数对径冗余、SLERP、$S^2$ / $S^3$ 上用归一化高斯均匀抽样（只回引）；本篇新增的是「在它上面量体积」这一面。

#### ③-1 最顺手的一套：欧拉角，在极点过密（验：等价 ≠ 好用）

- 锚定实例：ZYZ 欧拉角 $R=R_z(\alpha)R_y(\beta)R_z(\gamma)$，三个角各自等间距取点——这是写程序最顺手的做法。
- 具体结果：
  - Haar 测度在 ZYZ 下是 $\sin\beta\,d\alpha\,d\beta\,d\gamma$：体积元在 $\beta=0,\pi$ 处 → 0，Jacobian 在那里掉秩（3 → 2）。
  - 均匀取 $\beta$ 的网格在极点附近**过密**，而且过密的倍数不是一个固定数：普适的说法是相对密度 $\propto1/\sin\beta$、在极点**发散**。任何「几倍」都依赖于取多宽的极冠带——$\beta<\delta$ 这圈极冠带的份额比约为 $4/(\pi\delta)$，与带宽成反比：$\delta=10°$ 约 7.3 倍，5° 约 14.6 倍，1° 约 73 倍。正文若举数字，必须带上「取 10° 宽的极冠带时」这类限定，并点明带越窄倍数越大（2026-09-30 作者裁定：不把「约 7 倍」当普适结论）。赤道附近反而只有约 0.64 倍。
  - 方向要说准：体积元 $\sin\beta$ 是**趋零**，不是发散；发散的是它的倒数——把「欧拉角均匀」的样本当成 Haar 来用时，隐含的相对密度 $\propto 1/\sin\beta$，在极点处发散。
  - 这个掉秩点就是 ch5 的万向节锁死：$\beta=0$ 时 $\alpha$ 与 $\gamma$ 合成一个角。同一个奇点，ch5 从插值看，本篇从积分看。
  - 程序上的修法：整个 $SO(3)$ 上积分时欧拉角网格必须带 $\sin\beta$ 权；均匀抽样直接用归一化高斯四元数（LI `so3.haar_rotations`，与 ch5 同一个「偷懒办法」）。
- 数据出处：`code/check_orientation_space.py` [1]（10° 桶表 + 极冠带宽 δ → 份额比表）。
- 图占位：图 4（图表）——横轴 $\beta$，欧拉角均匀相对 Haar 的密度比 $2/(\pi\sin\beta)$（曲线）叠 10° 桶样本比值（点），读者要看到曲线在两极冲向无穷，而不是一个固定倍数。

#### ③-2 在姿态族上积分：用族自己的参数（用洞察 1）

- 角色：洞察 1 在程序上的回报——知道了族是环面 / 圆，就知道该用哪套参数。
- 具体结果：柱晶 $(\psi,\theta)$ 的诱导面积元是常数（实测 $\sqrt{\det J^\top J}\equiv1$），直接等间距即可；Parry、片晶只剩一个角，同理。Haar 样本筛出的柱晶赤道带，方位与自转两边际均匀、彼此独立（统计量见附录）。
- 数据出处：`code/check_orientation_space.py` [2]。

#### ③-3 在整个 SO(3) 上积冰晕：太阳在晶体里的方向 × 绕太阳的转角（立 + 转折）

- 锚定实例：固定太阳方向 $\hat{\mathbf s}$。任一姿态 $R$ 给出 $\mathbf u=R^{-1}\hat{\mathbf s}$（太阳在晶体系里的方向），剩下的自由度是整个晶体绕 $\hat{\mathbf s}$ 转一个角 $\theta$。
- 具体结果：
  - $SO(3)$ 分解为 $\mathbf u\in S^2$ × $\theta\in S^1$，Haar $=d\mathbf u\,d\theta$，不带权。数值：40 万个 Haar 样本映到 $(\mathbf u,\theta)$ 后，三个边际均匀、两两独立（$p$ 均在 0.4 以上）。
  - ch5 hist02 做过它的「另一半」：以 c 轴在世界里的方向 $R\mathbf e_3$ 为底的同一种分解；本篇换成以太阳在晶体里的方向为底——一个描述晶体朝哪，一个描述光从哪边打进来。为什么对冰晕好用（半径只看 $\mathbf u$）留给 ch10。
  - 转折：**好坐标也不是没有奇点。** $\theta$ 需要在每根纤维上选一个起点，这种选法没有处处光滑的：最短旋转取法在 $\mathbf u=-\hat{\mathbf s}$ 处失效，绕这一点走一小圈，起点转了 2 圈。对比柱晶环面是平凡的、选得出处处光滑的起点。好坐标的好处在于体积元没有权重、奇点只剩一个零测度的点——积分不受影响，而不是「没有奇点」。
  - 程序上：LI Phase II 就是这么积的——底空间 $S^2$ 上取等面积点、$\theta$ 在每个像素上被方位角直接吸收（LI `docs/phase2.md` §2）。
- 数据出处：`docs/framework.md` §4.1 定理 8；LI `docs/phase2.md` §1–2；`code/check_orientation_space.py` [4]。
- 图占位：图 5（A 类示意）——$S^2$ 底空间上每点竖一个小圆（$\theta$ 纤维），$-\hat{\mathbf s}$ 附近参考起点绕两圈。
- 收束（一张三行小表，可选）：场景 / 坐标 / 体积元——整个 $SO(3)$：欧拉角 + $\sin\beta$ 权，或 Haar 抽样；姿态族：族参数，常数；冰晕积分：$(\mathbf u,\theta)$，$d\mathbf u\,d\theta$。
