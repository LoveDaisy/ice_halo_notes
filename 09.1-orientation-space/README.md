## 图 3 局部候选（待作者审看）

![图 3 候选：Parry 共享圈的局部邻域](img/parry_neighborhood.png)

上半部只画 **Parry 圈附近的局部参数邻域**，不是两张完整环面在轴角球里的嵌入。坐标为 `R(φ,a,b)=Rz(φ)Ry(−90°+a)Rz(b)`：`a=0` 是柱晶带、`b=0` 是 Lowitz 带，`a=b=0` 是共享 Parry 圈。径向代表 `a`、竖向代表 `b`；它们不是晶体在物理空间里的平移，也不表示姿态距离。

片晶不在这个小邻域中，因此另用下半部的**整圈索引**交代：Lowitz 全摆幅 `t` 的 `0°` 是片晶圈、`−90°` 是 Parry 圈、`+90°` 是原始点集中的另一交圈，`−180°` 和 `+180°` 接回同一翻转片晶圈。roll 锁 0 的半环 `t∈[−180°,0°]` 只交出 Parry 一圈；商 D₆ 后两交圈属于同一物理 Parry 族。上图局部的 `a=t+90°`，不能把整个索引强行嵌进那条窄带。

`test_parry_neighborhood.py` 以独立体轴约束、局部 Jacobian 满秩、D₆ 群元素及实际成图命中点反解参数核验。此方案是“局部相交 + 全摆幅索引”的拆分候选，尚未插入正文。作者第三轮建议沿此表达扩展为下面的开窗环面；保留本版用于比较，不将启发性评价登记为最终签核。

## 图 3 扩展候选（待作者审看）

![图 3 扩展候选：两张开窗环面与两条原始交圈](img/intersecting_tori.png)

按作者第三轮意见把两张曲面扩展成可辨弯曲的环面部分：浅面为 Lowitz、深面为柱晶，两条橙线分别对应 `t=−90°` 的 Parry 圈与 `t=+90°` 的翻转交圈；蓝线为 Lowitz 上 `t=0°` 的片晶圈。前侧开窗露出内部，柱晶保留跨越两交圈的一段弯曲面。切口只删面片、不加封口，且不切断两条交圈；片晶圈前半段被开窗揭掉，图面明确说明它并没有从原姿态族中消失。背面被遮挡的交线不透画。

这是**集合关系示意**，不是整个 SO(3) 的三维欧氏嵌入，也不表示物理距离或均匀测度。用两个同轴显示环面表达环面与共享圈的关联：母圆半径同为 1、中心半径为 2.5 / 1.7，故显示交集恰为半径 2.1、高度 `±sqrt(0.84)` 的两圈。显示母圆角通过圆周重参数化对应实际姿态角，不能把图上高度或管角读成姿态角。

物理核验另走姿态约束：Lowitz 的 `R e₂` 水平、柱晶的 `R e₃` 水平，两者同时成立即 `R e₁=±e_z`。`test_intersecting_tori.py` 用 SciPy 独立生成姿态，从两族各自扫描得到两圈；再验证图中两面的同一个交点对应完全相同的旋转矩阵（两条圈上的柱晶方位配对不同）。全摆幅有两圈，roll 锁 0 的半环只有 `t=−90°`；D₆ 等价不能冒充原始点集相等。

渲染对两张开窗薄面分别求最近射线命中，统一深度比较；独立四次方程求根测试核对遮挡，实际像素反查体轴约束，两圈均有可见像素；引线端点也核验为可见点。字体/基础 palette 仍来自 ch8；新候选用冰蓝同色系明度区别两面、橙色强调共享圈，最终外观尚待作者裁定。

可运行 `uv run python 09.1-orientation-space/code/fig_intersecting_tori.py --output <PNG>` 隔离重生成。静态几何，无 Lumice / MC 数据；本图与旧局部版均未插入正文，先交作者目视后再决定保留哪一版。

## 图 3 径向剖切候选（待作者审看）

![图 3 径向剖切候选：母圆的两个交点各生成一条共享圈](img/tori_section.png)

按作者第四轮提议，沿过轴的两个径向半平面揭去前侧一段曲面，直接露出两个相交母圆；右侧小剖面将同一几何正视展开，不填充圆盘，不把曲面冒充实体。默认版采用**平齐切口**，同一切面能直接对照两个交点与上下交圈。上一版开窗图保留为基准，未修改。当前仍是样图，作者对上一版的“效果好多了”不是对此版本的最终签核。

切口只影响表面显示，不改变母圆、姿态映射及完整交圈。新图两条橙圈在揭面段用虚线补全，保留段为实线；两种线都遵守真实遮挡，不透画背面。深浅两面分别由副标题和小剖面标识；蓝色只强调 Lowitz 上的片晶圈，切边用灰色轮廓，避免与片晶混淆。上下交圈分别对应 `t=+90° / −90°`；原始点集、roll 锁 0 半环和 D₆ 商空间的区别与上一版一致。

`fig_tori_section.py` 调用 `fig_intersecting_tori.py` 的唯一曲面/姿态/射线渲染实现，只注入切口。错层候选让外环多揭一段、内环少揭一段；它更强调前后层次，但两个切边不再处在同一径向平面。可用以下命令在本地生成比较版，不替换默认图：

```bash
uv run python 09.1-orientation-space/code/fig_tori_section.py --variant staggered --output scratchpad/task-draw-ch9p1-ch10-figs/variants/tori_section_staggered.png
```

`test_tori_section.py` 从独立角度区间核对切口，以四次多项式全部实根核对像素/切边/两圈遮挡，并验证实际绘制的小剖面方程及交点、完整圈的闭合和两面姿态一致性。曲线在近切线处采用更紧精度与更多迭代，不能用面像素容差判断线条深度；旧版默认渲染参数不变。静态几何，不用 Lumice，无 MC 数据；两份新候选均待原尺寸目视裁定，不扩画其余图。
