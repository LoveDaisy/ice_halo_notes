### 像素能量怎么取

「能量」= 像素 sRGB 8-bit 解码成线性亮度（R+G+B）× 像素立体角（cos lat），全天求和。absolute 曝光下像素值与光线数无关（2×10⁷ vs 4×10⁷ 比 1.0015）、与
`intensity_factor` 成正比，所以**每份产出各自曝光、按 intensity 归一后比较**：

- 8-bit 量化对暗像素是净损失：余量图 i=0.2 时能量比 i=4 低 17%，全景 i=0.05 比 0.4 低 8%，90° 族 i=0.2 比 4 低 11%（2×10⁷ 探针）。所以每份产出先用 1/10 光线探一次，
  按线性亮度把关注区域最亮像素换算到 ≈ 200/255（`TARGET_PX`），正式渲染后最亮像素不在 [100, 254] 再修一轮（`_ch9_sim.exposed_render`）。
- 太阳盘（θ ≤ 1°）单独处理：0° 族里无反射的平行光路（`1-2`、`3-6`…）不偏折，全落在太阳 0.5° 盘内 4–8 个像素，任何能看清晕环的曝光都把它削顶。
  全景与 0° 族各多渲染一份 dim 曝光（`*_dim`，只取盘内），盘外取 bright 曝光，两段按 intensity 归一后相加（`total_energy_per_i`）。盘内能量占全天 11.4%。
- 像素积分 vs MC 光子计数是两条独立链路（D65 vs 550 nm、R+G+B vs 光度 Y、量化残余、噪声）。单轨道探针（2×10⁷）：`3-15` 10.30% vs MC 10.23%、`1-23` 2.07 vs 2.11、
  `3-6` 6.22 vs 5.73、`1-2` 0.63 vs 0.59（−2%…+9%）。

### 判据（机械，阈值与理由）

- **径向剖面**：以太阳为极点，像素按与太阳的夹角 θ 分 0.25° 桶，桶内平均辐亮度 Σ(L·w)/Σw（均匀背景在这条曲线上是平的）；能量占比看 Σ(L·w)。
- **峰 / 背景**：局部极大；背景 = 峰位 ±10° 窗内「非峰窗口」（剔除峰位 ±2°、8 个已知晕的环带 [R − 0.5°, R + 2.5°]、太阳盘外沿 θ < 2°）的中位数；
  **峰值 / 背景 ≥ 3 算「峰」**（plan 初值，未调）。不剔环带时 20°/22°/23°/24° 四环挤在 4° 里中位数被邻环抬高（20° 环峰值是环间底噪的 9.5 倍、却只有邻环中位数的 1.5 倍），
  剔了才是 plan 说的「非峰窗口」。
- **已知半径「可辨」**（全景）：过阈值的峰归到「峰位 − 0.25° 以下最近的已知半径」（峰在最小偏向角外侧：逐族图实测环内缘正落在 R，峰位 R + 0.4…1.9°），收到峰即可辨。
  未过阈的另记「弱峰」（局部极大但 < 3×）或「肩部」（窗内无局部极大）。
- **弧 / 点**（top-3）：环带 [θ − 0.5°, θ + 2.5°] 按绕太阳的方位角分 5° 格，格均值 ≥ 2 × 局部径向背景算亮起，亮起格占比 ≥ 10% 判 arc、(0, 10%) 判 spot、0 判 none。
  **随机取向下天空关于太阳方向旋转对称，任何光路的像都是整圈，这条判据在本场景退化**（覆盖率要么 ~1 要么 0）；真正区分「有自己的弧 / 散成背景」的是最亮处的径向峰/背景比，两个数都记。
- **族级能量容差**：相对 17% = 2 × 校准最大偏差。校准（scratchpad，2×10⁸，正式渲染前）：63.8° 族 +1.25%、0° 族 +2.5%、90° 族 −8.4%；按 plan「实测 Y 取 2Y」用最大的 8.4%。
  容差表达同一族两条链路的一致性，超出它才提示过滤器成员有问题；所有族的实际偏差照记。

## 3. 族外余量（`odd_radius_remainder`）——机械核对 2

过滤器：9 族 ≤4 面全部代表 207 条并集装一个 `complex(action="filter_out", PBD)`（issue 方案 (a)）；`filter_out` 语义先用单光路最小复现钉住：`filter_in(3-15)` +
`filter_out(3-15)` = 0.994 × 全部（2×10⁷ 探针，i=1.0；0.6% 的差额与「全部」图太阳盘削顶同量级，未单独分离）。方案 (b)（像素相减）因 (a) 通过核对未做。

- 曝光 i=5.21，最亮像素 145，无削顶；E/i = 6894.9，**份额 12.117%** vs MC 族外 5.7905% + 单面外反射 7.2518% = 13.0423%，相对偏差 **−7.1%，容差内**。
  偏差方向与 90° 族一致（余量是全天最弥散的成分，量化残余最大）。
- **径向剖面上没有一个峰过 3× 阈值**（`peaks == []`）。≥ 1.3× 的局部极大只有：θ = 2.6° / 3.1° / 5.1°（太阳周围雾的边缘，1.3–1.5×）、124.6°（1.55×）、176.6°（反日点附近，1.83×）。
- 能量分布：q10 / q50 / q90 = 14.4° / 74.1° / 134.6°；θ < 40° 占 33%（太阳周围单调衰减的雾；单面外反射与族外光路两部分未分离），θ > 120° 占 22.5%
  （反日侧一片弥散，图上能看出几道暗淡的同心弧但对比 < 1.9×）；辐亮度最低点在 θ ≈ 170°。
- **结论**：全天减去 9 族，剩下的散成背景——太阳周围的雾 + 反日侧的弥散，**没有自己的弧**（没有 ≥ 3× 背景的峰）。

- **三条光路的光都不在「楔角 → 最小偏向角」的半径上**（R 环带内能量全为 0），全在反日侧（q50 = 97° / 120° / 143°）。楔角只定颜色与偏向的大小，那一次中间反射（折叠矩阵 M）

- render 份额比 MC 低 2–21%：这三条的光散在半个天空，是全部产出里最弥散、量化残余最大的（偏差方向与 90° 族、余量一致）；没有为它们设容差，如实记。
- 60.7° 的 `13-15-26-28` 离 60° 族只差 0.7°（族归并容差 ±0.5°）却完全不在 22° 环上——「族外」不是「差一点就进族」，是折叠不同。

## 5. 给 §4 的一句话结论

默认档随机取向下，九族全景机械可辨的是 9° / 22° / 24° 三环（20° / 35° / 46° 有极大但不到 2.2 倍背景，18° / 23° 被邻环盖住）；逐族归因 9/9 与 MC 能量份额在 17% 内互证；
全天减去 9 族剩 12.1% 的能量，散成太阳周围的雾与反日侧的弥散，没有一个 ≥ 3× 背景的峰；族外能量前三的光路都带一次反射、光全在反日侧——族外没有自己的晕，ch9 的对象仍是 9 族。

## 6. 已知边界

- `max_hits=4`：正式插图若要含 5–7 面链的「更真」全景（能量多 ~8.6%），逐族 / 余量过滤器仍受 256 个过滤器上限约束（余量并集 1520 条放不下），需另想办法（拆多份 config 相加或等 Lumice 放宽）。
- 1440×720：20°–24° 四环相邻 1–1.8° = 4–7 px，剖面分得开；更高分辨率等 `projection.py` 的 matmul 修掉。
- 像素能量口径的系统偏差方向：越弥散越偏低（90° 族 −8%、余量 −7%、top-3 −2…−21%），是 8-bit 量化的已知性质，不是过滤器漏成员。
- 太阳高度只做了 20°；非随机取向（片 / 柱 / Parry）下的族外能量另议（scrum.md §5 追加项）。
