# 现代冰晕研究漫谈(10)：半径与方位

> 本篇知识点（拟）：出射点离太阳的角距离只看「太阳在晶体里的方向」$\mathbf u$（定理 8）、姿态族 = $\mathbf u$ 球上的可取集、Bravais 等效折射率、水平方位差与天球角距离的区别、最小偏向角

## 提纲

**本篇回答的问题：为什么幻日总在 22° 晕外面、太阳越高离得越远（高过约 60.75° 就消失），而切弧总是和 22° 晕相切？**

### 核心洞察

1. **三种姿态 = $\mathbf u$ 球上的三块地。** 离太阳多远只看太阳在晶体里的方向 $\mathbf u$（定理 8），所以一条光路的「半径」可以画成 $\mathbf u$ 球上的一张地形图 $D_P(\mathbf u)$；姿态唯一的作用是圈地——片晶圈一条纬度圆，柱晶圈一条总含赤道的带，随机取向圈整个球。幻日、切弧、22° 晕离太阳多远，都是「在自己那块地上找最低点」。一张图（图 3）就能看出来，全篇就是把这张图读三遍。
2. **（转折，不是并列的第二个洞察）两把尺子。** Bravais 等效折射率量的是**水平方位差**，地图量的是**天球角距离**；两者都随太阳升高变大，却不是同一个数（$h=40°$ 时差 8.7°，$h=60°$ 时差 54°）。它插在第一次读图（片晶外移）的中间：读者刚接受「太阳越高幻日越外」，正是最容易把两个量混成一个的时候。

全篇六节：§0 摆问题 → §1 立地图（坐标 + 三块地，不读数）→ §2 第一次读：片晶那条纬度圆（外移 →**转折：两把尺子**→ 出界消失）→ §3 第二次读：柱晶那条带（碰到全局最低点 ⇒ 相切）→ §4 第三次读：随机取向的全球（全局最低点 ⇒ 内缘，三次读数收拢到同一个 21.84°）→ §5 留局面。图 3 在 §1 打底，§2–§4 回到它，每次叠一层新标注。

### 0. 开场：同一条光路，三种离法（引出地图）

- 角色：把问题摆出来——幻日、切弧、22° 晕是同一条 `3-5` 光路（同一个 60° 楔）给的，离太阳的表现却三样。三样表现要一张图才装得下，§1 画这张图。
- 锚定实例：[[迷镜千幻不离宗|漫谈(1)]] 那张 `3-5` 光路模拟图（幻日、上下切弧、22° 晕同框），以及三个日常观察：太阳在地平线时幻日恰好贴着 22° 晕；太阳升高，幻日离开晕往外走；切弧不管太阳多高，都在晕的正上方 / 正下方贴着它。
- 具体结果：太阳高度 0° / 40° / 60° 时幻日到太阳的角距离 21.84° / 27.63° / 44.62°，22° 晕内缘恒为 21.84°；切弧切点恒在太阳正上 / 正下 21.84°。
- 数据出处：`code/check_parhelion.py` [1]、[3]。
- 图占位：图 1（仿真 / 回引）——`3-5` 单光路、片晶 + 柱晶 + 随机三种姿态叠在一张天空图上，两三个太阳高度并排；或直接回引 ch1 的 `halos_3-5.jpg`。

### 1. 立地图：离太阳多远只看 $\mathbf u$，姿态只管圈地

- 角色：画出全篇反复读的那张图——先说地图上的「高度」是什么（定理 8），再说三种姿态各圈了哪块地。本节只画布局，不读任何一种晕的数；删掉它，后面三次读数没有图可读。
- 锚定实例（地图的坐标）：一块冰晶、一条 `3-5`。把整块晶体**绕着太阳方向**转一个角度——太阳在晶体里的方向没变，光在晶体里走的路也没变，出射光只是跟着晶体绕太阳转了同样的角度。绕着太阳转的点，离太阳的距离不变。
- 具体结果：
  - 地图的高度（定理 8，直觉版）：姿态的三个自由度里，「绕太阳转」这一个只把光点沿着以太阳为心的圆搬动；剩下两个就是太阳在晶体系里的方向 $\mathbf u$（9.1 番外的好坐标）。所以角距离 $=D_P(\mathbf u)$，只由光路 $P$ 和 $\mathbf u$ 决定，与晶体怎么摆无关；**姿态唯一的作用是限定能取到哪些 $\mathbf u$**。「半径归光路，方位归姿态」——方位（落在圆上哪里）留给 ch11。
  - 地形：以晶体 c 轴为「北极」的 $\mathbf u$ 球，上面画 $D_P(\mathbf u)$ 的等值线（`3-5` 的地形图：最低点 21.84° 在赤道上，也就是光线在截面主平面内、对称穿过 60° 楔的那一点）。
  - 三块地（解析）：
    - 随机：$\mathbf u$ 取遍整个球。
    - 片晶（c 轴竖直）：太阳高度 $h$ ⇒ $\mathbf u$ 只能在**仰角 $=h$ 的一条纬度圆**上（晶体绕 c 轴转只改经度）。
    - 柱晶（c 轴水平）：$u_z=\cos h\cos(\psi-\text{太阳方位})$ ⇒ $\lvert u_z\rvert\le\cos h$，**一条总是包含赤道的带**。
  - 于是三个现象变成同一个问题：在自己那块地上，$D_P$ 最低能到多少——§2–§4 各读一次。
- 引用块（证据，不进主线）：
  - 地图只看光路的 $\Phi$（ch8 的 $M\circ W$），不看面序列本身：薄片晶里 `3-5` 直穿在太阳 40° 时就被底面截断（Lumice 0 亮像素），光改走 `3-2-1-5`（两次底面反射，$M$ 仍是 $I$、同一个 60° 楔），落点与 `3-5` 的幻日相同（差 0.06°，一像素内）。
  - 「与姿态无关」的一个侧面：柱晶三个太阳高度下 $D_{\min}$ 不变；柱晶可取 $\lvert u_z\rvert\in[0,\cos h]$ 数值确认。
- 数据出处：`docs/framework.md` §4.1 定理 8；`code/check_parhelion.py` [0]（`3-5`、`3-2-1-5` 都是 $M=I$、楔角 60°）、[1]（纬度圆）、[3]（柱晶 $D_{\min}$ 与可取带）；`code/check_parhelion_lumice.py` [L3]（薄片晶 $h/a=0.3$）；9.1 番外 ②（各姿态族的形状）、③-3（$(\mathbf u,\theta)$ 坐标）（已对照 9.1 现行标题核实②/③-3 编号）。
- 图占位：图 2（A 类示意）——太阳方向做轴，晶体绕它转一个角度，光点在以太阳为心的圆上跟着转。图 3（图表，本篇核心图，本节打底）——$\mathbf u$ 球上 $D_P$ 等值线 + 三块地的轮廓（片晶纬度圆、柱晶带、随机 = 全球）；此处不标各自的最低点，留给 §2–§4 回到这张图时逐次叠加。

### 2. 第一次读地图：片晶那条纬度圆（外移 → 转折：两把尺子 → 出界）

- 角色：地图的第一次读数，也是最长的一次——同一条纬度圆随 $h$ 的连续读数：先往北移、圆上最低点跟着升高（外移），移到头整条圆出了可行域（消失）；中间插「两把尺子」转折。删掉它，读者没见过「地块一动、最低点跟着动」，§3「带子永远碰得到最低点」就失去对照。
- 回到图 3，这次看：几个 $h$ 的纬度圆，各自圆上的最低点。
- 锚定实例：光线斜着穿过 60° 棱镜。沿棱方向（竖直）的分量在两次折射中都不变（两个面都是竖直的），变的只是截面里的分量。
- 具体结果（外移）：
  - 直觉：把光线投影到截面上看，它像是在一块「更稠」的棱镜里走——等效折射率 $n'=\sqrt{n^2-\sin^2h}/\cos h$（Bravais）随 $h$ 变大，同一个 60° 楔偏得更多，幻日就更外。
  - 光点与太阳同高度：竖直分量不变 ⇒ 纬度圆上**每一点**的光点仰角都等于 $h$（数值到 $10^{-14}$）。这就是幻日为什么水平地排在太阳两侧。
  - 数：$h=0°/20°/40°/55°/60°$ 时幻日角距离 21.84° / 23.07° / 27.63° / 36.43° / 44.62°，单调外移；$h=0$ 时纬度圆就是赤道，最低点与 22° 晕内缘重合。
- **转折：两把尺子。**（刻意不设标题：它的身份是片晶读数中间的一次纠偏，不是一次独立读数；写法同 9.1 番外 ③-3 的「转折：」段。位置紧跟上面「外移」的数字，放在「出界」之前，不挪到节末。）
  - 读者刚接受「Bravais 棱镜越稠、幻日越外」，最容易把 Bravais 的「偏了多少度」当成「离太阳多远」。不是同一个数：Bravais 的等效棱镜给的是**投影到水平面上的方位差** $\Delta\varphi$，最小值 $2\arcsin(n'/2)-60°$；地图的高度 $D_P$ 是**天球上的角距离**。两点同高度 $h$，换算是球面余弦定理 $\cos D=\sin^2h+\cos^2h\cos\Delta\varphi$。
  - 锚定 $h=40°$ 的幻日：$\Delta\varphi=36.32°$，$D=27.63°$，差 8.7°；$h=60°$：$\Delta\varphi=98.78°$，$D=44.62°$。方位差到 60° 附近已经超过 90°，而角距离还不到 45°——高太阳时两把尺子差得很远。
  - 本篇讲「半径」一律用角距离 $D$（与定理 8 同口径、与 22° 晕可直接比）；$\Delta\varphi$ 只在解释 Bravais 直觉时出现。
- 具体结果（出界）：
  - 回到图 3：等效折射率随 $h$ 一路变大；到 $n'=2$ 时，60° 棱镜对截面里的光处处全反射——不管从哪个方位射进来，第二个面都出不去。在地图上看，就是那条纬度圆整条出了 `3-5` 的光学定义域：地块还在，只是整块都不能走了。
  - 数：$n'=2\iff\sin^2h=(4-n^2)/3$，$n=1.31$ 给 $h_c=60.753°$。消失前一刻幻日离太阳约 49.7°（$h=60.75°$），能透过的方位只剩约 1°。
  - 说准「消失」的含义：这是光学上的消失，与晶体形状无关（$\Phi$ 只看两个面的法向）。厚度只会让 `3-5` 更早被底面截断，但 §1 引用块那条 `3-2-1-5` 会接班，落点不变——亮度怎么掉是另一个问题，不在本篇。
- 与前文的关系：8.1 番外 §2–3 已经提过 Tape 用 Bravais 定律写 halo function，并给过 $h=0–30°$ 的幻日内边数字（与本篇脚本到 $10^{-4}$° 一致）；本篇不重讲 Tape 的写法，只补「为什么」这一层直觉和 $h$ 到 60° 的全段。
- 引用块（证据，不进主线）：
  - 第二条链路：Lumice 片晶渲染（同一个 $n=1.31$）读出的幻日内缘在 $h=0/20/40/60°$ 与上面差 +0.04 / +0.06 / +0.06 / −0.06°，均在一个像素（0.25°）以内。
  - 两把尺子三条路两两对上：数值 $D_P$ 最小值、由数值 $\Delta\varphi^\ast$ 经球面余弦换算的 $D$、Bravais 闭式 $\Delta\varphi$，11 档 $h$ 残差都 $<10^{-6}$°。
  - 临界高度：直接在纬度圆上二分「还有没有一个方位能透过」得到 60.75341°，与闭式差 $10^{-6}$°。
- 数据出处：`code/check_parhelion.py` [1]（外移数字；$\Delta\varphi^\ast$、球面换算 $D$、Bravais $\Delta\varphi$ 三列；$h=60.75°$ 行：可行弧长 1.02°、$D=49.67°$）、[2]（二分 vs 闭式）；`code/check_parhelion_lumice.py` [L1]、[L3]；8.1 番外 `08.1-tape-vs-matrix/data/crosscheck_b_inner_edge.csv`（$h=0–30°$ 同组数字）。
- 图占位：图 3 本次叠加——几个 $h$ 的纬度圆及其最低点，含离开可行域的那条。图 4（A 类示意）——斜穿棱镜的光线分解成沿棱分量 + 截面分量，截面里画等效的「更稠」棱镜。图 5（图表）——幻日角距离 $D$ 与水平方位差 $\Delta\varphi$ 随 $h$ 的两条曲线，22° 水平线，60.75° 竖线（数据 `check_parhelion.py` [1]）：两条曲线的分叉是「两把尺子」转折的证据图，竖线是出界。

### 3. 第二次读地图：柱晶那条带（碰到全局最低点 ⇒ 相切）

- 角色：第二次读数，与 §2 成对照——片晶的地（纬度圆）只有 $h=0$ 时才碰到赤道，柱晶的地（带）永远包含赤道。删掉它，「走不走得到最低点，决定贴不贴 22° 晕」这条对照只剩一半。
- 回到图 3，这次看：柱晶那条带，和全局最低点所在的赤道。
- 锚定实例：太阳高度 20°，c 轴水平的柱晶。
- 具体结果：
  - 柱晶那条带总包含赤道 ⇒ 能取到全局最低点 ⇒ 切弧离太阳最近处恰好是 $D_{\min}=21.84°$，也就是 22° 晕的内缘——**相切**。与太阳高度无关（0° / 20° / 45° 三档到 $10^{-7}$° 相同）。
  - 切在哪：取到最低点时 c 轴水平且与太阳方位垂直，出射光留在「垂直于 c 轴、过太阳」的那个竖直面里 ⇒ 切点在太阳**正上方和正下方** 21.84° 处（上切弧、下切弧）。
  - 为什么只切一点：带上其余的 $\mathbf u$ 都比最低点高，所以弧上其余各点都在晕外。弧的形状、两翼怎么张开，是「落在圆上哪里」的问题，留给 ch11。
  - 对比 §2：片晶那条纬度圆只有 $h=0$ 时才落在赤道上，所以只有太阳在地平线时幻日才贴着晕。
- 引用块（证据，不进主线）：第二条链路——Lumice 柱晶 $h=20°$ 读出切点离太阳 21.875°（像素中心），方位 −0.125°、仰角 41.875°，与上面差 0.04°。
- 数据出处：`code/check_parhelion.py` [3]；`code/check_parhelion_lumice.py` [L2]。
- 图占位：图 3 本次叠加——柱晶带（一个 $h$）及带上的最低点（= 全局最低点，落在赤道上）。图 6（A 类示意）——c 轴水平且垂直于太阳方位的柱晶，出射光留在过太阳的竖直面里，天空上切弧与 22° 晕在正上方相切。

### 4. 第三次读地图：随机取向的全球（三次读数收拢到同一个 21.84°）

- 角色：最后一次读数，也是洞察 1 的合拢——地就是整个球，最低点就是全局最低点。三种晕的「最近处」都是同一个 60° 楔的最小偏向角，差别只在各自那块地走不走得到最低点。删掉它，前两次读数里的「全局最低点」落不到读者最熟悉的 22° 晕上。
- 回到图 3，这次看：整张图都是地，最低点就是赤道上那一点。
- 具体结果：$\mathbf u$ 取遍整个球 ⇒ 最低点就是全局 $D_{\min}$ ⇒ 内缘在 21.84°，与幻日（$h=0$）、切点同一个数。
- 与前文的关系：本篇只讲内缘的**位置**，不讲它为什么**锐**。前文给过两件相关的工具：[[平行光路的各种弧和晕|漫谈(3)]] 讲平行光路（楔角 0）绕主轴旋转不改变出射方向、所以能量集中；[[蒙特卡洛 vs. 直接积分|漫谈(6)]] 讲直接积分时每个像素是沿一条 1 维姿态曲线的积分。两者是「光怎么堆」「亮度怎么算」的工具，不是对 22° 晕内缘的解释（`docs/errata.md` #8）。内缘为何锐利、是有限跃变还是发散、切弧接触点为什么更亮，留给 ch12。
- 数据出处：`code/check_parhelion.py` [3] 小结行（$D_{\min}$ 闭式 $2\arcsin(n/2)-60°$ 与数值一致）。
- 图占位：图 3 本次叠加——整球着色为「可取」，全局最低点（§2 $h=0$、§3 已标过）即内缘。

## 附录 / 引用块计划

- 定理 8 的推导：$\mathbf x=-R\,\Phi_P(-R^{-1}\mathbf s)$，$\angle(\mathbf x,\mathbf s)=\angle(-\Phi_P(-\mathbf u),\mathbf u)$；两个负号的由来（$\Phi_P$ 吃入射传播方向，光点是出射传播方向的反向）；$SO(3)$ 按 $\mathbf u\times\theta$ 分解（引 9.1 附录，不重推）。
- Bravais 等效折射率推导：斜入射分解为沿棱 + 截面分量，Snell 定律在截面上的形式 $n'=\sqrt{n^2-\sin^2h}/\cos h$；截面最小偏向 $\Delta\varphi_{\min}=2\arcsin(n'\sin30°)-60°$。
- 球面余弦换算 $\cos D=\sin^2h+\cos^2h\cos\Delta\varphi$，以及为什么幻日与太阳同高度（竖直分量守恒）。
- 临界高度闭式：$n'=2\iff\sin^2h_c=(4-n^2)/3$，$n=1.31$ ⇒ $h_c=60.753°$。
- 柱晶可取 $\mathbf u$ 的带 $\lvert u_z\rvert\le\cos h$ 的推导，以及切点方向（c 轴 $\perp$ 太阳方位时出射光在过太阳的竖直面内）。
- 数值口径（引用块）：LI 与 Lumice 同用 $n=1.31$（Lumice 冰折射率按 Sellmeier 随波长变，580 nm 时为 1.3100000，550 nm 时 1.311013，故渲染取 580 nm）；日面取 0.02°（高太阳时 $dD/dh\approx4$，默认 0.2° 日面会把幻日内缘往里拉约 0.4°）；1440×720 全天图、像素 0.25°。
