## 写法约定

- **不写「框架阐述」章。** 每章锚定一个前几章已经埋下、尚未兑现的悬念，用一个具体结果把它收口；框架只作为结果的副产品浮现。每章配一份计算机核验（群论论证只给上界，可达性 / TIR / 亮度都在论证之外，穷举才把结论钉死）。
- **一篇只回答一个问题，锚一个具体实例。** 担心一篇讲太多分散注意力，是 2026-09-26 这次重排的起因；不在一章里塞进多条线索。
- **正文直白，严谨论证 / 复杂公式放引用块（`>`）或文末附录。** 参考样板：《光学系统像差杂谈（10）：冲破枷锁的曲折之路》（https://zhuanlan.zhihu.com/p/600142236 ，vault `Writing/articles/` 有本地副本）——只借「推导进附录」这一点，节奏按本系列自己的来。
- **前文已讲过的不重复。** ch9 已讲「能量与拥挤」决定可见性、已用片晶三联图预告姿态；ch5 已讲欧拉角 vs 四元数、SLERP、对径认同、极点奇点、SO(3) 均匀分布。
- **规划随新事实随时修改。** 规划时没有的事实，出现后就改规划——本次重排即一例：Lumice Integral（下称 LI）2026-09-25 的数值裁定推翻了原 ch10「两种聚光」部分前提，原 ch10/11 因此拆分重组。

## 主线

整个系列分两部分：**正向问题**（给定冰晶与光路 → 天上出现什么）与**反向问题**（看到什么 → 反推冰晶与光路）。0–6 章是正向问题的第一遍叙述；写作时思路尚不成熟，几处没讲透。7–12 章（含 8.1 / 9.1 / 12.1 三篇番外）用群论 / 等变映射 / 奇点 / 姿态分布的语言把正向问题重新提炼一遍，然后转入反向问题（13 起）。

正向深化的三条主线说明（细节见 framework.md）：

1. **结构 vs 巧合**：六棱柱「无限多光路 → 12 个反射矩阵 → 6 类晕」是晶体学巧合（镜面夹角 60°/90° 恰是 Coxeter 角）；等变分解 $\Phi = M\circ W$、signature 分类、两种聚光机制才是结构。锥晶（ch9）是分辨二者的试金石。
2. **半径归光路，方位归姿态**：出射点到太阳的角距离只由晶体坐标系里的偏折角决定，姿态分布只决定每个太阳同心圆的方位填充。ch10 讲半径，ch11 讲方位。
3. **反问题是线性反问题**：前向模型对姿态测度 $\rho$ 线性，所有非线性都在光路侧。Hough 投票 = 伴随算子（backprojection），可微渲染 = 同一算子的正则化求解。这段过渡放在 ch13 开篇，不单独成章。

正向深化之所以先于反向问题，不只是叙事顺序：它把方向映射收成可控的假设空间——六棱柱是精确有限类（34），锥晶是「9 个直接楔家族 + 显式字长截断」——直接缩小反向问题的假设空间。
