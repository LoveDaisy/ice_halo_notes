> 2026-09-11 起草。章节内容由作者定，本文只固定结构与线索；「需要的能力」一列是 `halo_notes/` 的需求清单来源。

## 主线

整个系列分两部分：**正向问题**（给定冰晶与光路 → 天上出现什么）与**反向问题**（看到什么 → 反推冰晶与光路）。0–6 章是正向问题的第一遍叙述；写作时思路尚不成熟，正向问题还有几处没讲透，计划先用几章把正向问题用群论 / 对称性 / 不变量 / 吸引子与奇异点这类更「现代化」的语言重新提炼一遍（前几章已有迹象），再转入反向问题。深化章的选题另起 session 专门讨论。
