# 插图风格规范

> **代码是唯一权威**：色值、线型、语义 token 住在 `halo_notes/draw/style/`（`palette` 颜料 →
> `mapping` 语义 → `figure_scheme()` 解析入口），色值对照表由
> `uv run python -m halo_notes.draw.style.table` 生成（`docs/figure-style-colors.md`，
> freshness 测试比对生成物）。本文只写代码表达不了的部分。
> 文字规范与判例取舍由作者裁定；判例是判例，不是硬规则。

## 取色入口（先读这个）

新章画图不要写十六进制色值，也不要用颜料名表达概念（`PAL["face_5"]` 这类以出处命名的取色
是颜料层的内部视线）。正确姿势：

```python
from halo_notes.draw.style.figure import figure_scheme
S = figure_scheme()          # 篇内所有图共用一个 scheme
S.family["plate"]            # 语义槽：取向族 / 太阳 / 光点 / 二元对照 / 曲面 / 地形色阶 / 晶体、球面
figure_scheme(sun_color="accent_warm")   # 篇内覆盖：传 mapping 字段名，不是全系列硬映射
```

颜色-语义一致的作用域是**篇内**：同一篇里同一概念同色同记号；跨篇不强制，从画面综合审美出发
（作者 2026-10-30：某篇没有太阳，金色线段完全可以挪作他用）。机械闸
`halo_notes/repo/tests/test_figure_style.py` 拦闸内各章的十六进制字面量。

## 图面解剖

- 图内**无大标题 / 副标题 / 底部脚注**：一句话结论交给正文的「图 N：」图注（#48 的 18 图全部照此执行）。
- 图内只留**读图必需的直接标注**；标签贴着元素本体写，不用长引线穿图。压线 / 压元素时给文字加纸色描边
  （`patheffects.withStroke`），或挪到线外侧、空白象限。
- 多面板允许面板小标题（「正穿 · h = 0°」），但小标题不承担图注职能。
- 仿真参数（太阳高度、光线数、seed……）不进图面，留在脚本头注释与 provenance（ch8 惯例）。

## 免责 / 限定性说明的准入

- **准入标准**：只为「读者会误读」处保留；图注一句话能说清的就不进图面。
- 不出现正文没有的行话（#48 删掉过「roll 锁 0」「原始点集」——图面文字读者读不懂就是失败）。
- 倾向于用**直接标签**陈述事实（「留白：无可行出射方向」「整球可取」「k_z 相同」），
  而不是写一段免责声明；限定语（「不是亮度」「不表示强度或可见截止」）移入图注。
- 判例库：#48 逐图处置（B.2 表）记录了每处图面文字的「原图面文字 → 去向」；新图拿不准时先看同类情形当时是怎么处置的。

## 字号（知乎栏宽）

- 折算公式：**显示 px = 字号 pt × dpi / 72 × 栏宽 / 图宽 px**。机械折算，不凭观感。
- 栏宽假设 **690 px**（桌面端正文栏，未实测——作者发布预览时核对一张；手机端约 343 px，全部减半，需点开大图）。
- 闸：`test_figure_style` 的字号下限（显示高 ≥ 8 px，≈ #47 脚注档的失误线；现状最小 8.2 px）。
- 已知短板：宽图（2400–2600 px）主体标注折算后约 9 px（正文 15 px 的 0.6 倍）；要明显改善只能收窄画布或
  减面板——改构图，**是否值得由作者决定**（#48 B.6 折算表留档）。

## 记号约定（与颜色并行）

- 太阳：天象 / 天球上是**金色圆点**；方向示意是金色箭头。不再有星形、白点。
- 光线箭头：纸面**实心小三角**，三维图与俯视图同形（锥体在近端会看成圆环，弃用）。
- 对径认同 /「同一个」：两端同一空心记号 + 虚线括号，不画「走过去」的弧（9.1 图 1 判例）。
- 可取集合画在地形上：**族色边界线 + 带外压淡 / 留白处淡染**，不把族色半透明叠在地形上（混色发泥）。
- 小尺寸晶体：**不标背面 / 镜像编号**（镜像变形字缩小后成乱码）；正面贴面编号**面心水平正放**
  （随姿态倒置的「3」读成「ε」）。`crystal_preset()` 已内置这套规则。
- 数学一律 mathtext；数学下标不许裸写 `_`（闸 2 拦截）。中文混排段包 `\mathrm{}`（ Hiragino 渲染），
  局部 rc 经 `fig_plate_terrain.math_rc()`，不要全局 `rcParams.update`。
- 不用颜色单独编码读者必须分辨的含义：颜色 + 直接标签 / 线型 / 点型共同区分。

## 投影

- 三维示意图一律**透视投影**（`Camera(projection="perspective")`，#47 确立）：正交投影会把透视压缩
  误读成形状变化（「Haar 边缘更密」错觉的教训；需要时按可见性调点大小补偿并写进图注）。
- **二维曲线 / 点云保持二维**：平面投影不冒充三维空间，横向取模、剖面平移都要在图注说清是什么。

## 审美判例（作者裁定存档，最终解释权在作者）

- **族色用系列蓝 / 红及近邻**（2026-10-30 第一轮）：「此前的系列文章里往往会用蓝色和红色作为两种区分明显的主色……绿松石 + 琥珀……和我们这个系列有点不搭」。
  判例拼版：`09.1-orientation-space/img/compare_orientation.png`（含被否方案的历史样图）。
- **曲面 S1 冰蓝 + 淡珊瑚、地形 T3 中性石板、太阳金色**（2026-10-30 第二 / 三轮）：「曲面的冰蓝+珊瑚配色我觉得挺好……地形我也认同你的判断」「太阳用金色我觉得没问题」。
  判例拼版：`10-radius-and-azimuth/img/compare_radius.png`。
- **语义作用域篇内**（2026-10-30 第三轮）：「在同一篇文章里保持颜色-语义的对应是有道理的……跨篇章的话就不必严格遵循，还是需要从画面综合审美角度来综合判断」。
- 终审签核（2026-10-30）：18 图全部采纳、字号暂按现状；签核基线即当时两章 `img/`。
