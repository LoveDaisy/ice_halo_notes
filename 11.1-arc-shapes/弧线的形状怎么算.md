## 提纲

**本篇回答的问题：天上那么多弧，古典几何流派是怎么一条条算出来的？和本系列的矩阵算法是什么关系？为什么今天大多数弧我们干脆不算了？**

### 核心洞察

1. **「一条弧」有三种来历，古典几何对每种各有一招，矩阵法一个公式全包。** 姿态族本身只有 1 维（偕日弧、Parry 弧）——像就是弧，光点法画成「圆锥 ∩ 天球」；族有 2 维但一个自由度被吃掉（特里克尔弧：绕 c 轴转不改出射方向）——像塌成弧，ch3 的矩阵推导与 TM2006 的光点图得到同一个 30° 圆锥；族有 2 维、像也有 2 维（切弧、Lowitz 弧）——我们叫「弧」的是这一片像的**亮边**，古典作图的办法是在每根轴上取偏折最小的那一点。本系列 $\mathbf x=-R\,\Phi(-R^{T}\mathbf s)$ 一个公式覆盖三类；在切弧上，它与 Pernter / Tricker 1970 的球面三角逐点一致到 $10^{-12}$°。一张图（图 2：三类来历并排）就能看出来。
2. **最小偏折不等于亮边——古典作图在 Lowitz 上画的是另一条线，这才是计算机接手的真正原因。** 「每根轴上取偏折最小」能落在亮边上，条件是「绕 c 轴转」本身是姿态族里的一个方向：柱晶满足（切弧上两条线逐点相同），Lowitz 族不满足——同一招画出的线离真正的亮边（天空映射 Jacobian 降秩的 fold）中位 1.65°、最远 22.9°，只在贴 22° 晕的那一小段重合。亮边要解「Jacobian 行列式 = 0」，Tape 1980 也只能数值求解；而数值积分 / 仿真把整片像算出来，亮边自己显出来。大多数弧不必再算，不是因为算不出，而是解析作图最自然提的问题（哪里偏折最小）不一定是天空回答的问题（哪里最亮）。

全篇：§0 摆问题 → §1 立地图（三种来历）→ §2 用在前两类（圆锥 ∩ 天球，古典与矩阵是同一个公式 / 同一个锥）→ §3 用在第三类并验（切弧：球面三角 vs 矩阵，1970 手算表 vs 精确几何）→ §4 转折（同一招在 Lowitz 上画错线，洞察 2）→ §5 收束（什么时候解析式仍值得、什么时候交给计算机）→ §6 留局面。§2–§4 都以「这是地图上的第几类」开头；删掉 §1，§2–§4 只剩三个互不相干的例子；删掉 §3，§4 没有对照（「同一招」的「同」无从说起）。

口径（全篇统一，附录说明）：光路 `3-5`（$M=I$、60° 楔）只用于切弧与 Lowitz；$n=1.31$（Tricker 1970 书 p.74 与 Tape 系列同值）；Lowitz 的数值与 ch11 同一口径（太阳 15°、单条标号光路、Lumice / LI 的 roll 锁 0 定义）；切弧用 Tricker 表的四档太阳高度 0 / 10 / 20 / 30°。

### 0. 开场：同一个圆锥，两种算法；那么多弧呢？（摆问题）

- 锚定实例：[[平行光路的各种弧和晕|漫谈(3)]] 的特里克尔弧——矩阵推导得到「$\mathbf r'-\mathbf s_a$ 落在与竖直成 30° 的圆锥面上」，ch3 正文当时就提了一句「Angle x 书里是用这样的几何图景描绘偕日弧的」；TM2006 p.71 用光点图把偕日弧、下反日弧、反日弧（= 特里克尔弧）都画成圆锥 ∩ 天球。同一件事，两种算法。
- 具体结果：不给新数字；提出问题——古典流派还算过哪些弧、怎么算的；本系列怎么算同一批弧；为什么后来大多不算了。

### 1. 立地图：一条弧的三种来历

- 角色：全篇的地图。后面每一节都先说「这是第几类」；删掉它，§2–§4 是三个互不相干的例子。
- 锚定实例：ch11 §1 的维数工具 $\dim(\text{像})=\dim Q-\dim(\text{纤维})$（只回引）；三类各举一个已经见过的弧。
- 具体结果：
  - **第一类：族是 1 维，像就是弧。** 偕日弧（Parry 族，一次反射）、各种 Parry 弧（ch11 §2：Parry 族像 1 维）。
  - **第二类：族是 2 维，但一个自由度被吃掉，像塌成弧。** 特里克尔弧：柱晶族 2 维，平行光路绕 c 轴转不改出射方向（ch3），纤维 1 维。
  - **第三类：族是 2 维，像也是 2 维；「弧」是这片像的亮边。** 切弧（ch11 §3：柱晶像是一片，切片式填充）、Lowitz 弧（ch11 §4：Lowitz 像是一片）。这时候要算的不是「像」，而是「像的边」。
  - 本系列一条公式 $\mathbf x=-R\,\Phi_P(-R^{T}\mathbf s)$ 对三类都一样；区别只在后处理——第一、二类直接把族映过去，第三类还要找边。古典几何则每类一招（§2、§3）。
- 数据出处：ch11 提纲 §1–§4 与 `11-five-halos-one-wedge/code/check_pose_shapes.py` [1]–[5]（维数）；ch3 第 102 行（不含 $\theta$）。
- 图占位：图 2（A 类示意，核心图，洞察 1）——三栏：左「1 维族 → 弧」（Parry 圈 → 偕日弧），中「2 维族、塌掉一维 → 弧」（柱晶环面 → 特里克尔弧，纤维画成箭头），右「2 维族 → 一片，弧 = 边」（柱晶环面 → 切弧那片，边描粗）；每栏下方写古典那一招（圆锥 ∩ 天球 / 同上 / 每根轴取最小偏折）与本系列那一招（同一个 $\mathbf x(R)$）。

### 2. 用在前两类：圆锥 ∩ 天球——古典与矩阵是同一个公式

- 角色：地图的第一、二类。这两类里古典光点法漂亮，而且与矩阵法看得出是一回事；同时引出 TM2006 自己的一句提醒——这种漂亮来自「退化」。
- 锚定实例：
  - 偕日弧（第一类）：「光路本质上是斜侧面的一次反射……每个晕点是把太阳光点沿反射面法向投影；Parry 取向下法向与水平成 30°，晶体绕竖直转时法向扫出顶点在太阳、半顶角 60° 的竖直圆锥，偕日弧就是这个圆锥与天球的交」[TM2006 p.71]。矩阵法写同一件事：一次反射 $M=I-2\mathbf n\mathbf n^{T}$，$\mathbf H=\mathbf S-2(\mathbf S\cdot\mathbf n)\mathbf n$——**逐字是同一个公式**，光点法的「沿法向投影」就是反射矩阵。
  - 特里克尔弧（第二类，不重算）：ch3 已用矩阵法得到「与竖直成 30° 的圆锥」；TM2006 同页说下反日弧是「顶点在下反日点、半顶角 30° 的圆锥 ∩ 天球，但更难看出为什么」，反日弧把图对水平面镜像——顶点在反日点，正是 ch3 的 $\mathbf s_a$。
- 具体结果：
  - ch3 的参数方程逐点满足「$\mathbf r'-\mathbf s_a$ 与竖直成 30°」，残差 $4.7\times10^{-11}$°（太阳 0 / 15 / 30°）；$\mathbf r'-\mathbf s_a$ 的竖直分量正负都出现，即 ch3 那个系数 $A(\alpha)$ 会变号——弧落在圆锥的**两叶**上（作者原想法里「双圆锥」的准确含义）。
  - 说准一句（TM2006 原话转述）：CZA 和上 suncave Parry 弧能画成圆锥 / 平面，是「一种退化」，不代表一般的晕 [TM2006 p.70]；46° Parry 弧「让计算机画光点图很容易，但画出来没什么帮助」[TM2006 p.71]。光点法漂亮的地方，恰好是像已经是 1 维的地方。
- 引用块（证据，不进主线）：脚本 [3] 的残差与两叶判据。
- 数据出处：`code/check_tangent_arc.py` [3]；[TM2006 p.70–71] Figs. 6.9、6.11；[TM2006 p.207]（helic / anthelic 是 TM2006 对 heliac / Tricker arc 的改名）；ch3 第 104–140 行。
- 图占位：图 1 已回引；另可改绘 TM2006 Fig. 6.11 左（偕日弧的光点图）放在本节，标出「沿法向投影 = 乘反射矩阵」。

### 3. 用在第三类并验：切弧——Pernter / Tricker 的球面三角 vs 矩阵法（锚定实例）

- 角色：地图的第三类，也是全篇双写的锚。古典流派在这里换了一招：不再画像，而是在每根轴上挑一个点——偏折最小的那一点——再把这些点连成线。本节验证这招与矩阵法算出的是同一组点，并说清这组点为什么恰好是亮边（为 §4 的转折埋条件）。
- 锚定实例：Tricker 1970 转述并推广 Pernter 的切弧理论（书 p.108–113，Fig. IV:43–45）：柱晶 c 轴 $P$ 在地平圈上，与太阳成 $\theta$；偏折最小的光点 $M$ 满足 $PM=PS=\theta$、$\angle MPS=D(\theta)$（法平面里的最小偏折，Bravais）、$SM=\Delta$；由 $\sin\omega=\sin\theta\sin D/\sin\Delta$、$\sin\beta=\sqrt{\sin(\theta+\Sigma)\sin(\theta-\Sigma)}/(\sin\theta\cos\Sigma)$ 得 $M$ 以太阳为极点的极坐标 $(\Delta,\ \sigma_1=180°-\beta-\omega)$（上切弧）、$(\Delta,\ \sigma_2=\beta-\omega)$（下切弧）。Tricker 给了太阳 0 / 10 / 20 / 30° 四档的逐点表（Table IV:3）。本系列：c 轴水平、方位 $\arccos(\cos\theta/\cos\Sigma)$ 的柱晶绕 c 轴转一圈，对 $\mathbf x=-R\,\Phi(-R^{T}\mathbf s)$ 的偏折数值求极小。
- 具体结果：
  - **两种算法是同一组点**：100 个最小偏折点（四档太阳 × 13 根轴 × 上下两支），Tricker 公式与本系列数值极小的 $(\Delta,\sigma)$ 最大差 $2.6\times10^{-12}$°。$\theta=90°$（轴与太阳垂直）时两点落在太阳正上 / 正下 21.8393°——即 ch10 的切点。
  - **1970 年的手算表也对得上**：Table IV:3 共 53 行，与精确几何常规行最大差 2.6′（表印到整弧分，Pernter 的 $D,\Delta$ 表本身与 Bravais 链差 ≤ 2.5′）。
  - **为什么这组点就是亮边**（为 §4 埋条件）：对固定的轴，绕 c 轴转时光点沿一条线走，偏折最小处光点在这条线上掉头——$\partial\mathbf x/\partial(\text{roll})=0$；而 roll 恰好是柱晶族的一个方向，于是天空映射的 Jacobian 在这里降秩，这正是像的 fold（亮边）。实测：柱晶族的最小偏折轨迹 1640 点到 fold caustic 的距离最大 $2.1\times10^{-6}$°——两条线逐点相同。Tape 1980 早已指出：最小偏折轨迹在切弧（与幻日）上就是 caustic [Tape1980 p.15]。
  - 与 ch11 的衔接：太阳 15° 时 $\Delta=25.1°$ 处上切弧点在位置角 ±17.3°、下切弧点距正下方 1.6°——ch11 §3 那张「切片式填充」表（±18° / ±2°，1° 格）的上沿，就是这条线。
- 与 ch10 / ch11 的分界：ch10 讲切点为什么在正上 / 正下、为什么相切；ch11 讲柱晶像铺成哪一片；本节讲那一片的**边**怎么算、古典和本系列各怎么算。
- 引用块（证据，不进主线）：同一姿态下 8.1 已验证的 TK1999 光点公式与 $\Phi=M\circ W$ 光点差 $3.1\times10^{-12}$°（第三条链路）；1970 表的两处出入见附录。
- 数据出处：`code/check_tangent_arc.py` [0]–[2]、[4]（column 行）；[Tricker1970 书 p.98] Table IV:1、[书 p.108–113] Fig. IV:43–45、Table IV:2–3；Tape 1980 Eq. (31)（切弧的 generating set，8.1 源笔记 §1.3）与 [Tape1980 p.15]。
- 图占位：图 3（A 类示意）——改绘 Tricker Fig. IV:43 / 45：天球上的球面三角 $PMS$、$PST$，标 $\theta,D,\Delta,\omega,\beta$。图 4（数值）——太阳 0 / 10 / 20 / 30° 四格，每格画本系列算出的上下切弧曲线，叠上 Tricker Table IV:3 的 53 个印刷点，再叠 22° 圆。

### 4. 转折：同一招在 Lowitz 上画错了线

- 角色：洞察 2。§3 的招数有一个条件——「绕 c 轴转」是族里的方向；Lowitz 族没有这个方向。删掉它，本篇只剩「古典 = 矩阵」的一半，回答不了「为什么今天不算了」。
- 锚定实例：古典流派确实给过 Lowitz 弧的构造。Tricker 1970 回顾了 Pernter 的振荡理论与 Fujiwhara–Oti 的「伪 Lowitz 弧」[Tricker1970 书 p.91–93]，再给出自己的 spinning crystal 理论：对每个 $\theta$，解球面三角求「光最强的点（即他所说的 mock sun，最小偏折）」，这些点的轨迹就是弧——「解球面三角虽有点繁琐，但没有困难」[书 p.100]；他的曲线过幻日、与 22° 晕相切，「符合 Lowitz 弧的大致形状」[书 p.102，Figs. IV:31–32]。这正是 §3 那一招。本系列：ch11 §4 的 Lowitz 族（单条 `3-5`、太阳 15°），在同一族上分别求「绕 c 轴偏折取极小」的点（古典的线）与「天空映射 Jacobian 行列式 = 0」的点（亮边）。
- 具体结果：
  - **两条线分开了**：Lowitz 族的最小偏折轨迹 556 点，到最近 fold caustic 的距离中位 1.65°、95% 分位 17.8°、最大 22.9°；63% 的点离开超过 0.5°。只在 $D\in[21.84°,22.50°]$ 那一小段（贴 22° 晕、幻日一带）重合——与 Tape 1980 的说法一致：side arc 上最小偏折轨迹一般不是 caustic，「对」的点只有幻日与圆晕切点附近 [Tape1980 p.15]。
  - **为什么**：Lowitz 族的两个方向是「绕竖直转」和「绕长对角线摆」；绕 c 轴转不在族里，最小偏折处的 $\partial\mathbf x/\partial(\text{roll})=0$ 不再迫使族上的 Jacobian 降秩。§3 的「巧合」其实是柱晶族的特殊性。
  - **亮边要怎么求**：解「$\ker JF$ 与族的切平面有交」——Tape 1980 把它写成方程组 Eq. (33)(34)，也只能数值求解、画进 Figs. 9–13 [Tape1980 p.15]。Greenler 1978 干脆用计算机随机取晶体姿态做光线追迹，直接得出 Lowitz 弧的模拟图 [Greenler1978 p.1]；TM2006 也说简单的自旋晶体能把形状模拟对，强度却要调晶体形状和姿态才对上 [TM2006 p.73]。
  - 说准一句：这里不是「Lowitz 的形状没有解析解」（这是没法证明的负面命题），而是「古典作图最自然的那一招，问的不是天空回答的问题」。
- 引用块（证据，不进主线）：脚本 [4] 两族对照（柱晶最大 $2.1\times10^{-6}$° vs Lowitz 中位 1.65°），caustic 采样点距（柱晶 0.015°、Lowitz 0.058°）。
- 数据出处：`code/check_tangent_arc.py` [4]；ch11 `check_pose_shapes.py` 的姿态链与 `sky`（按路径复用）；[Tricker1970 书 p.91–93, p.100–102]；[Tape1980 p.15] Eq. (33)(34)；[Greenler1978 p.1]；[TM2006 p.73]。
- 图占位：图 5（数值，洞察 2）——左右两格：左柱晶、右 Lowitz（太阳 15°、单条 `3-5`），各画族的像（灰）、fold caustic（实线）、最小偏折轨迹（虚线）；左格两线重合，右格两线分开、只在 22° 晕附近汇合。

### 5. 收束：解析式还剩什么用，什么时候交给计算机

- 角色：把「计算机暴力碾过去」那一半说准。前四节已经给出判据，这里收成两句话，不再加新事实。
- 锚定实例：[[冰晕模拟仿真的朴素思路|漫谈(4)]] 的渲染方程、[[蒙特卡洛 vs. 直接积分|漫谈(6)]] 的直接积分（每个像素是沿一条 1 维姿态曲线的积分）；本系列一直的做法——把整片像算出来，边与亮度自己显现。
- 具体结果：
  - **解析式仍值得的时候**：给位置的闭式（ch10 的切点、本篇的切弧表，手算可查）；判断几何性质（圆锥、两叶、相切、对称）；做数值结果的校验尺——本篇脚本本身就是例子：数值极小要靠 Tricker 的闭式来确认没算错，反过来闭式也靠数值确认没抄错。
  - **不值得的时候**：像是 2 维、亮边又不是最小偏折轨迹的弧（Lowitz）；光路复杂到光点图不再启发的弧（TM2006 说第 8 章之后不再画光点图 [TM2006 p.50–51]）；以及所有要问「多亮」的问题——那是 ch12 的事。
  - 一句收拢：古典流派把力气花在「从 3 维姿态里挑出 1 维」上，挑得对（第一、二类，切弧）就漂亮；本系列把 $\mathbf x(R)$ 写成一条公式、整片算完再看边，不需要挑，也就不会挑错。
- 数据出处：ch4、ch6 正文（只回引）；[TM2006 p.50–51]（8.1 源笔记 §3.1）。
- 图占位：无（或图 6：Lumice 柱晶 / Lowitz 族下单条 `3-5` 的渲染，与图 5 同视野，看亮边自己显现；待裁定 7）。

- **锚定实例为什么选切弧、不选偕日弧**：偕日弧是一次反射，光点法与矩阵法是同一个公式，「双写」退化成恒等式；切弧的古典算法是另一种古典流派（球面三角作图，不是光点法），而且 Tricker 印了逐点数值表，是一条与本系列不共享任何代码的历史证据链。特里克尔弧按作者要求不重算，只在 §2 做数值确认。
- **Tricker 1970 表的两处出入**（正文不写，附录一句）：Table IV:3 中 $\theta=65°$ 一行（$\Delta=23°50'$）的 $\sigma_0$ 印 5°45′，精确值 5°38.7′，四档太阳高度一致偏大约 7′；Table IV:2 首行 $\sigma=2°45'$ 与同书 Table IV:3 同一量的 1°58′ 不一致，公式给 1.977°（IV:2 那行有误）。掠出射端点行（$\theta=29°15'$）差 45.8′——端点对 $\theta$ 极敏感（$\theta_{\min}=29°14.8'$，差 0.2′ 时 $D$ 就从 120° 掉到 118.55°），不算错。
- **数值口径**：切弧——对 roll 的 0.1° 网格找局部极小，再有界一维极小化到 $10^{-11}$°；单条标号光路在一个 c 轴指向下只给一个极小，轴线的两个指向（az、az + 180°）各给上 / 下切弧之一。最小偏折轨迹 vs caustic——族参数网格（方位 0.2°、第二参数 0.5°）上沿两个方向找 $\partial\Delta/\partial\psi$（$\psi$ = 绕 c 轴）与 $\det[\mathbf x,\partial_a\mathbf x,\partial_b\mathbf x]$ 的变号点、各二分 40 次；最小偏折只留 $\partial^2\Delta/\partial\psi^2>0$；距离是轨迹点到最近 caustic 点的角距离（caustic 采样点距柱晶 0.015°、Lowitz 0.058°，是距离的分辨率）。
- **Jacobian 降秩的推导**（§3、§4 的「为什么」）：族参数 $(a,b)$，天空映射 $\mathbf x(a,b)$；柱晶 $b$ = roll，最小偏折处 $\partial_b\mathbf x=0$ ⇒ 秩 ≤ 1；Lowitz 的 $(a,b)$ = (方位, 摆角)，$\partial_\psi\mathbf x=0$ 不落在 $\mathrm{span}(\partial_a,\partial_b)$ 的约束里。对应 Tape 1980 的判据：奇点 ⇔ $\ker JF$ 含一个与族曲面相切的向量 [Tape1980 p.14]。
