## 提纲

**本篇回答的问题：同一条 `3-5` 光路（同一个 60° 楔），为什么能变出圆晕、幻日、切弧、Parry 弧、Lowitz 弧？它们之间是什么关系？**

### 核心洞察

1. **姿态族的包含关系原样搬到天上，Parry 是中转站。** 9.1 番外在姿态空间里看到：Parry 加上绕 c 轴的自转就是柱晶，Parry 加上绕长对角线的摆动就是 Lowitz，Lowitz 摆到头就是片晶——几块形状咬在 Parry 上。同一条光路把姿态映到天空，子集的像仍是子集：Parry 弧同时躺在切弧那片和 Lowitz 那片里，幻日挂在 Lowitz 那片的下边上，全部落在 22° 晕的整圈里（`check_pose_shapes.py` [8] 逐点核验，四条包含全部成立）。一张图（图 3：以 Parry 为中心排开的五格，每格叠上它的子族）就能看出来。
2. **「单边」不是物理，是标号。** 天空的左右镜像，落在 Lowitz 那条摆动链上就是「绕 Parry 对折」（摆角 $\zeta\mapsto180°-\zeta$）：Parry 在折痕上，所以 Parry 弧单条 `3-5` 就对称；片晶在链的一端，它的镜像伙伴（翻面片晶、左幻日）在另一端，理想片晶族够不着，所以只有幻日单边。完整的晕要把同一个楔的 12 条标号光路合起来。这是 ch1 思考题的答案，也是洞察 1 那条链的第二次使用。

全篇：§0 摆问题 → §1 立工具（像有几维）→ §2 立枢纽 Parry → §3、§4 从 Parry 往两个方向松开一个自由度（柱晶、Lowitz），每次验一条包含 → §5 沿 Lowitz 摆到底（片晶），验接触方式 → §6 收进随机 → §7 转折：同一条链回答 ch1 思考题（洞察 2）→ §8 收束（卷积比喻说准，可降附录）→ §9 留局面。§3–§6 都以「接着上一节松开 / 摆到哪一步」开头；删掉 §2，§3、§4 失去出发点，删掉 §4，§5 与 §7 的链断开。

口径（全篇统一，附录说明）：太阳高度 15°（与 LI canonical scene 一致，便于对照）；五族取理想化极限（宽度 → 0），只有 Lowitz 保留天顶角分布（宽 40°）作权重；「位置角」= 光点绕太阳的方向，0° 正上方、±90° 两侧（+ 侧即 LI 所说的 right）、±180° 正下方；姿态族口径为 Lumice / LI 的 roll 锁 0 定义（Lowitz 即摆角 $\zeta\in[0°,180°)$、roll = 0 的那半张环面），包含关系在原始点集意义下成立，不需要对称操作。

### 0. 开场：ch1 的思考题（摆问题）

- 角色：把全篇的问题摆出来——同一条光路、同一个半径，天空上是五种不同的东西；它们是五样互不相干的东西，还是一家人？
- 锚定实例：[[迷镜千幻不离宗|漫谈(1)]] 的 `3-5` 光路模拟图与它的思考题——「为什么只有幻日是单边的，上下切弧、帕里弧、22° 晕都是完整的」。ch1 当时只说了「3-5 与 3-7 分别是右 / 左幻日」，没说为什么别的晕不单边。再加 ch10 尾声留下的局面：半径已经说完，「片晶是两个点、柱晶是两段弧，那 Parry、Lowitz 呢？」
- 具体结果：不给数字；提出本篇的问题，预告走法——从 Parry 这个中转站出发，把五族串成一条链，§7 用同一条链回答思考题。
- 数据出处：ch1 正文（`01-symmetry/迷镜千幻不离宗.md` 第 48–50 行附近）；ch10 提纲 §5（尾声）。
- 图占位：图 1（回引）——ch1 的 `halos_3-5.jpg`。

### 1. 立工具：同一个楔，像有几维

- 角色：后面每一节都要说「这一族的像是线还是面」，本节先给这把尺子。它不是链上的一环，是走链时用的工具；删掉它，§2–§6 的「一条弧」「一片」就没有依据。
- 锚定实例：9.1 番外 ②-1 的五族形状（只回引，不重讲）：随机 = 整个 $SO(3)$（3 维）、片晶 = 一个圆（1 维）、柱晶 = 一个环面（2 维）、Parry = 环面上一条纬线（1 维）、Lowitz = 另一张环面上的一条宽带（2 维）。
- 具体结果：
  - 天空是 2 维，所以一个姿态族的像最多 2 维；多出来的维数被「纤维」吃掉——同一个光点对应的一整族姿态。$\dim(\text{像})=\dim Q-\dim(\text{纤维})$，是 ch7「四锐两散」那条维数公式的推广（ch7 的纤维来自与 $R_z(\theta)$ 对易；这里 `3-5` 的 $M=I$，纤维来自别处）。
  - 实测（天空映射 Jacobian 的秩，每族 40 个内点）：随机 3 → 2（纤维 1 维）、片晶 1 → 1、柱晶 2 → 2、Parry 1 → 1、Lowitz 2 → 2。
  - 于是：片晶、Parry 给**线**（幻日 + 拖尾、Parry 弧），柱晶、Lowitz、随机给**面**（其中锐利的边就是我们叫它「弧」的那条线——为什么边锐利、为什么亮，是 ch12 的事）。
  - 与前文的衔接（一句）：本篇只讲像的位置与形状；前文讲「光怎么堆」「亮度怎么算」的工具——[[平行光路的各种弧和晕|漫谈(3)]] 的平行光路（楔角 0）绕主轴旋转不改变出射方向、所以能量集中，[[蒙特卡洛 vs. 直接积分|漫谈(6)]] 的直接积分每个像素是沿一条 1 维姿态曲线的积分——都不是内缘为何锐利的解释（`docs/errata.md` #8），锐利留给 ch12。
- 与前文的关系：ch7「四锐两散」讲的是反射矩阵 $M$ 的对易性吃掉维数；本篇 `3-5` 的 $M=I$，对易总成立却不塌缩到点（楔角不为零，定理 8 的 $D_P$ 不是常数），塌缩由姿态族本身的维数决定。这层区别是否进正文列入待裁定 4。
- 数据出处：`code/check_pose_shapes.py` [1]–[5] 各族首行（「姿态族 k 维，天空像的维数 …」）；9.1 番外 ②-1（`09.1-orientation-space/code/check_orientation_space.py` [3]）。
- 图占位：图 2（A 类示意）——五族在姿态空间里的形状按「链」排开：Parry 那一圈居中，左边柱晶环面、右边 Lowitz 环面（引 9.1 图 3），Lowitz 环面一端是片晶圆，外框是随机；每块旁边标它的天空像维数（线 / 面），中间箭头标「纤维」。

### 2. 立枢纽：Parry——两张环面的交，一条不碰 22° 晕的弧

- 角色：链的中心。先把 Parry 立住，后面两节都「从 Parry 出发，松开一个自由度」；删掉它，§3、§4 没有出发点。
- 锚定实例：9.1 番外 ②-2 的主图：柱晶环面与 Lowitz 环面咬在一圈上——这一圈就是 Parry（柱晶 roll = 0 那条纬线 = Lowitz 摆到 90° 那一圈，原始点集意义下逐点相等）。直观几何：Parry 是 c 轴水平、面 3 朝上锁死的柱晶；放开绕 c 轴的自转就成了柱晶，放开绕长对角线的摆动就成了 Lowitz。
- 具体结果：
  - 像是 1 维：一条弧，顶点在太阳正上方 $D=31.46°$（仰角 46.46°），两翼向两侧下垂到 $D=44.43°$（位置角约 ±65.5°）；$D=40°$ 处位置角 ±59°。
  - **不碰 22° 晕**：最近处 31.46° 远大于 21.84°——锁住 roll 之后，$\mathbf u$ 走不到 60° 楔的最小偏向方向。
  - 单条 `3-5` 就左右对称（各 50 %），落点全在太阳之上：这是 LI 所说的「上方 suncave Parry 弧」（为什么单条就对称，§7 用链来回答）。
  - 预告：接下来两节从这条弧出发，各松开一个自由度，看它落进哪一片。
- 引用块（证据，不进主线）：LI 对照——仰角 1/50/99 百分位 31/45/46°（LI 30/45/48°）、方位 −38/0/38°（LI −40/−1/36°）。
- 数据出处：`code/check_pose_shapes.py` [4]；9.1 番外 ②-2（`check_orientation_space.py` [5]）；LI §5.2 parry 行。
- 图占位：图 3 中心格（见配图表）。

### 3. 用：从 Parry 松开自转——柱晶，Parry 弧躺在切弧那片里

- 角色：链的第一条边。接着 §2，把面 3 朝上的锁放开、让晶体绕 c 轴自由转——Parry 那一圈扩成柱晶的整张环面；天空上，Parry 那条弧扩成一片，第一次验「子集的像仍是子集」。
- 锚定实例：ch10 §3：柱晶那条带总包含赤道 ⇒ 取到全局 $D_{\min}$，切点在太阳正上 / 正下。放开自转之后，$\mathbf u$ 终于走得到最小偏向方向——这正是 Parry 弧碰不到 22° 晕、切弧却贴着它的原因。
- 具体结果：
  - 像是 2 维的面（不是一条线）；最近处 $D=21.84°$ 在正下方（太阳 15° 时下切点在地平线下，仰角 −6.84°），正上方同样取到。
  - 每个半径圆被填上的位置角（上方 / 下方）：$D\approx22.5°$ 时 ±9° / ±2°，$25°$ 时 ±18° / ±2°，$30°$ 时 ±33° / ±1°，$40°$ 时 ±61° / ±11°（1° 格；下方 ±1–2° 已到分辨率）。离晕越远，上方那段张得越开——这就是切弧两翼向外张开的形状；太阳 15° 时上下两段不对称（上宽下窄）。
  - **验包含**：Parry 弧的每一点都落在这片里（6 万个点到柱晶像的最近邻距离最大 0.17°，不超过该处网格分辨率）。$D=40°$ 处 Parry 弧在 ±59°，切弧那片上方一段是 ±61°——Parry 弧就在上翼里面走。
  - 上下各半：像的姿态测度 50.0 % 在太阳之上、50.0 % 在之下；单条 `3-5` 已经左右对称（+侧 50.1 %、−侧 49.9 %）。
- 与 ch10 的分界：ch10 只说了切点在哪、为什么相切；本节讲两翼怎么张开，以及 Parry 弧在里面。
- 引用块（证据，不进主线）：LI 对照——仰角 1/99 百分位 −27/55°（LI −27/55°）、方位 −39/39°（LI −40/37°）。中位数不作对照：像上下各半、中间 0–20° 仰角几乎没有质量，中位数落在空隙里（本篇 16°、LI 32°），对采样噪声极敏感。
- 数据出处：`code/check_pose_shapes.py` [3]、[8]（parry ⊂ column）；LI §5.2 column 行。
- 图占位：图 3 左格（柱晶，叠 Parry 弧虚线）。另可配图 4（图表）——横轴 $D$、纵轴被填上的位置角范围，五族各一条带，一眼看出「切片式填充」与包含。

### 4. 用：从 Parry 松开摆动——Lowitz，Parry 弧也躺在这一片里

- 角色：链的第二条边。回到 §2 的 Parry，这次锁住自转、放开绕长对角线的摆动——Parry 是摆到 90° 的那一圈，往回摆、往前摆扩成 Lowitz 的那张环面；天空上再验一次包含，同时为 §5（摆到 0）、§7（摆到 180°）铺好这条链。
- 锚定实例：9.1 ②-1、②-2：Lowitz 是 $\{R: R\mathbf e_2\ \text{水平}\}$ 那张环面，摆角 $\zeta$ 从 0（片晶）经 90°（Parry）到 180°（翻面的片晶）；LI / Lumice 的 Lowitz 权重是 $\zeta$ 宽 40° 的高斯，集中在片晶一端。
- 具体结果：
  - 像是 2 维的面；最近处能取到 $D_{\min}=21.84°$，位置角 +76.5°（方位 +22.5°、仰角 18.9°）——在 22° 晕上、幻日稍上方。
  - 每个半径圆被填上的位置角：$D\approx22.5°$ 时两侧各一段 ±[61°, 87°]，$25°$ 时 ±[44°, 87°]，$30°$ 时 ±[15°, 86°]，$40°$ 时 [−88°, 88°] 连成一片；正上方一段越往外越被填满；各档位置角都在 ±88° 以内，不到太阳的水平两侧以下。
  - **验包含**：Parry 弧的每一点也落在这片里（中位距离 0.03°；最大 1.11° 出现在 Parry 弧两端 $D\approx44.4°$——光学定义域边上，Lowitz 网格相邻一行已出界、另一行每摆 1° 天空位移约 6–7°，最大值不到该处网格分辨率的一半）。所以 Parry 弧同时属于切弧那片和 Lowitz 那片——姿态空间里「两张环面交于 Parry」，在天空上就是「两片像都包着 Parry 弧」。
  - 支撑对称、亮度偏一侧：单条 `3-5` 的落点集合左右对称，但按天顶角权重（偏向接近片晶的小摆角）加权后方位中位数在 + 侧（23°）——靠近片晶的那部分就是右幻日附近（§5 接着说）。98.7 % 的质量在太阳之上。
  - 说准一句：本篇的「Lowitz 弧」只指这片像，里面哪几条线最亮、是否对应观测上的上 / 中 / 下 Lowitz 弧，属于亮度问题，不在本篇。
- 引用块（证据，不进主线）：LI 的百分位是在显著样本上不加权取的（支撑集上的 Haar 测度），按同口径本篇为仰角 16/38/56°、方位 −37/4/39°，LI 表为 15/39/56°、−35/10/39°；按族密度加权则为 15/30/55°、−29/23/42°（口径差别见附录）。
- 数据出处：`code/check_pose_shapes.py` [5]、[8]（parry ⊂ lowitz）；LI §5.2 lowitz 行；LI `scripts/compare_pose_density_families.py::landing_map`（百分位口径）。
- 图占位：图 3 右格（Lowitz，叠 Parry 弧虚线与幻日线）。

### 5. 验：沿 Lowitz 摆到底——片晶，幻日挂在 Lowitz 那片的下边上

- 角色：链的端点，也是包含关系最有看头的一次验证。接着 §4，把摆角摆回 0——Lowitz 收成片晶；天空上，这一片收成一条线（幻日 + 拖尾），而且这条线不是从片中间穿过，而是贴在片的边上。观测上「Lowitz 弧从幻日出发」，形状层面的原因就在这里。
- 锚定实例：片晶只剩绕竖直轴转一圈（1 维），ch10 §2 已给出光点与太阳同高度。
- 具体结果：
  - 像是 1 维：一条沿幻日环（仰角恒 = 15°，数值到 $10^{-9}$°）往外走的线。离太阳最近处 $D=22.52°$（= ch10 的幻日距离），往外一直拖到 $43.38°$。
  - 每个半径圆只被填上**一个点**：$D\approx22.5°/25°/30°/40°$ 处位置角 +86 / +86 / +85 / +84°（1° 格内）。所以「幻日」是这条线上离太阳最近、最亮的那一端，往外的部分是幻日的「尾巴」（亮度沿线怎么分布是 ch12 的事）。
  - **只在 + 侧**：单条 `3-5` 的全部光点都在太阳同一侧（100 %）。左幻日来自 `3-7`（位置角 −86.942°，与 `3-5` 的 +86.942° 精确镜像）。为什么，见 §7。
  - **验包含 + 接触方式**：整条线落在 Lowitz 那片里（最近邻最大 0.15°）。沿线看两侧：从幻日（$D=22.52°$）到 $D\approx31.4°$，Lowitz 那片只在它上侧——摆角从 0 起摆一点，光点就往上走（100 %）——这一段幻日线是 Lowitz 那片的**下边**；再往外（拖尾外段，$D\gtrsim31.4°$ 到 43.38°），摆角约 1°–60° 的 Lowitz 姿态从下侧折回来，拖尾穿进 Lowitz 那片的内部。
  - 同时说清一个容易混的点：Lowitz 那片离太阳最近处在 $D=21.84°$、位置角 +76.5°（幻日上方），不在幻日（22.52°、+86.94°）。Lowitz 从幻日出发往上长，贴 22° 晕的地方却在幻日上方。
- 引用块（证据，不进主线）：LI 对照——仰角 1/50/99 百分位 15/15/15°（LI 14/15/16°，LI 片晶宽 0.5°）、方位 23/27/44°（LI 24/26/40°）。
- 数据出处：`code/check_pose_shapes.py` [2]、[6] 末行、[8]（plate ⊂ lowitz 与接触方式）；LI §5.2 plate 行。
- 图占位：图 3 右下格（片晶）；图 3 右格里把幻日线叠在 Lowitz 那片上，标出「边」段与「穿入」段。

### 6. 收束：全都在随机里——每个半径圆整圈填满

- 角色：把链整个收进最大的那一块。前面四族都是随机取向的子集，它们的像都落在 22° 晕这片里；随机那一格同时回答「22° 晕为什么是完整的圆」。删掉它，链没有外框，§8 的「均匀时是天空上的卷积」也没有实例。
- 锚定实例：ch10 §1 的「绕太阳转一圈」：随机取向下，绕太阳方向的转角 $\theta$ 均匀、与 $\mathbf u$ 独立（9.1 ③-3）。
- 具体结果：
  - 每个半径圆被填上的位置角：$D\approx22.5°/25°/30°/40°$ 都是整圈 360°（Haar 200 万样本、1° 格）。整圈是定理 8 的直接推论，不依赖数值。

  - 前四族像全在这个范围内、全在整圈里（平凡包含，不另核验）；四族里只有柱晶、Lowitz 取到内缘 21.84°，片晶（15° 太阳下）与 Parry 取不到——谁走得到最小偏向方向，是 ch10 那张 $\mathbf u$ 球地图的事。

### 7. 转折：为什么只有幻日是单边的——镜像就是绕 Parry 对折

- 角色：洞察 2。用 §2–§5 立起来的同一条链，回答 §0 的思考题；由此说清「一条标号光路」和「一个命名晕」的关系。删掉它，§0 的问题没有答案。
- 锚定实例：把天空沿过太阳的竖直面左右翻一下（$\sigma_w$），同时把晶体沿底面上下翻一下（$\sigma_h$）。上下翻不动任何一个柱面，所以 `3-5` 还是 `3-5`。
- 具体结果：
  - 镜像判据：姿态 $R$ 的像左右翻过来，恰好是姿态 $\sigma_wR\sigma_h$（仍是真旋转）的像（5000 个 Haar 姿态残差 0）。所以**单条 `3-5` 的像左右对称，当且仅当姿态族在 $R\mapsto\sigma_wR\sigma_h$ 下不变**。这个映射把 c 轴天顶角 $\zeta$ 变成 $180°-\zeta$、面 3 的朝上朝下不变。
  - 放回链上看：在 Lowitz 那条摆动链上，$\zeta\mapsto180°-\zeta$ 就是**绕 Parry（$\zeta=90°$）对折**。Parry 在折痕上 ⇒ 映回自己 ⇒ 单条 `3-5` 就对称；柱晶（$\zeta=90°$、roll 全取）同理；随机是全集，自然不变。片晶在链的一端（$\zeta=0$），对折到另一端 $\zeta=180°$——c 轴朝下的片晶。物理上它和 c 轴朝上是同一块冰，但面的标号顺序反了过来，`3-5` 在它上面给的是另一侧幻日（位置角 −86.942°）。理想片晶族只含 $\zeta=0$ ⇒ 单边。
  - Lowitz 两端都够得着：摆幅取全时，Lowitz 那片的另一端挂着左幻日（翻面片晶的像同样 ⊂ Lowitz 像，左幻日离它 0.025°）——所以单条 `3-5` 的 Lowitz 像集合左右对称；但 $\zeta=180°$ 处天顶角权重只有 $\zeta=0$ 处的 $4\times10^{-5}$，亮度全在右幻日一端（§4「支撑对称、亮度偏一侧」的来历）。
  - 所以「单边」不是物理，是**标号**：一条标号光路配一个标号姿态族，看到的只是一个物理晕的一部分。完整的晕是同一个楔的 12 条标号光路（`3-5`、`3-7`、`4-6`、`4-8`…，从侧面 $k$ 入、$k\pm2$ 出；全部 $M=I$、楔角 60°）合起来——点群轨道求和。C6 那一半可以直接搬到姿态上：`k-(k+2)` 在 $R$ 下 ≡ `3-5` 在 $R\,R_z(60°(k-3))$ 下（残差 $3\times10^{-15}$），即 framework §5.1「真正的卷积在 $SO(3)$ 上」的一个具体例子。
  - 12 条合起来（正文一句，细节进附录）：片晶每个半径圆两个点（左右幻日）；四族合起来的像全部左右对称；Parry 12 条里只有 6 条有像、三对各给一支——「Parry 弧」本身是一族弧，`3-5` 只给其中上方 suncave 那一条。
  - 书名的准确含义：「同一个楔」指同一个 $\Phi$ 类（ch8 意义下同一个 60° 楔），不是同一条标号光路。
- 与前文的关系：ch1 的 P / D 对称性（HaloPoint 2.0）就是这里的 C6 与竖直镜面；本节给出它为什么只对幻日「看得出来」。ch8 的 $\Phi$ 类只回引。
- 数据出处：`code/check_pose_shapes.py` [6]（12 条、C6 等变、轨道求和对称、左右幻日）、[7]（镜像判据、逐族映射 $\zeta\mapsto180°-\zeta$、片晶翻面）、[8]（翻面片晶 ⊂ Lowitz、左幻日到 Lowitz 像 0.025°、$\zeta=180°$ 处权重）；LI `docs/ch11-pose-density-families.md` §6 第 1 条（「群级叠加属于写作项目的理论章节」）。

## 附录 / 引用块计划

- 五族的精确定义与姿态链：$R=R_z(\text{az}-180°)\,R_y(-\zeta)\,R_z(\text{roll})$，roll = 0 ⇔ 面 3（体 $\mathbf e_1$）在过 c 轴的竖直面内朝上；Lowitz 绕体 $\mathbf e_2$（长对角线方向）摆（脚本 [0] 自检）。写作系列 `column_attitude` 的 $\theta=\text{roll}-180°$（引 LI `docs/ch11-pose-density-families.md` §2，不重推）。
- 理想化口径：宽度 → 0；Lowitz 天顶角分布按球面密度取，参数网格权重 $g(\zeta)\sin\zeta$，$g$ 为宽 40° 的高斯。
- 维数判据：天空映射 Jacobian 的奇异值，相对阈 $10^{-6}$，每族 40 个可行内点。
- 百分位口径：LI §5.2 在显著样本（$\rho>10^{-3}\max$）上不加权取百分位；本篇给加权与 LI 口径两套，只有 Lowitz 两者不同。柱晶中位数不作对照（双峰）。
- 镜像判据推导：$\sigma_h$ 固定所有柱面 ⇒ `3-5` 的 $\Phi$ 与 $\sigma_h$ 对易；$x(\sigma_wR\sigma_h)=\sigma_w\,x(R)$；映射在 $(\zeta,\text{roll})$ 上的作用 $\zeta\mapsto180°-\zeta$、roll 不变。
- 包含关系在天空上的核验口径（脚本 [8]）：子族像每点到父族像（`sample_family` 同一套网格）的最近邻角距离，容差取**逐点**局部网格分辨率（子族姿态在父族参数里挪半步到四个角点，取可行角点的最大天空位移）× 2；实测 d / 局部分辨率最大 0.93。固定全局容差不合适：Parry 弧两端 $D\approx44.4°$ 处光学定义域边上天空映射被拉伸，局部分辨率达 2.75°。接触方式：沿片晶线 1876 点、1° 邻域、0.05° 阈看 Lowitz 像点在线的哪一侧；转折点 $D\approx31.44°$。
- 12 条合起来的细节（原 §7）：Parry 12 条里只有 6 条有像——`3-5` 与 `3-7` 给的是**同一条**上方弧（顶点 31.46°），`4-8` / `8-4` 在更高处（$D\in[34.33°, 43.25°]$、位置角 ±8.8° 以内），`5-7` / `7-5` 在太阳正下方（最近处 $D=21.975°$，离 22° 晕内缘只差 0.14°）；柱晶与单条 `3-5` 的位置角集合相同（只多了亮度）；Lowitz 合起来把太阳以下也填上（$D\approx22.5°$ 时位置角 [61°, 299°]，即除正上方 ±61° 之外的全部）。

- 本篇未做：无限长棱镜（不含几何走廊、入射面积、Fresnel 透过率），所以这里的「权重」只是姿态测度，不是亮度。

8. **主线走向**（本轮新增）：选了「Parry 为枢纽的链」（Parry → 松开自转 = 柱晶 / 松开摆动 = Lowitz → 摆到底 = 片晶 → 收进随机），没选「按包含从小到大」（片晶 / Parry → 柱晶 / Lowitz → 随机）。理由：从小到大会退回「维数清单」；链式顺序直接对应 9.1 ②-2 的主图，且 §7 的「绕 Parry 对折」只有在链上才说得出来。若作者更想要从小到大，只需重排 §2–§6 顺序与过渡句，核验不变。
