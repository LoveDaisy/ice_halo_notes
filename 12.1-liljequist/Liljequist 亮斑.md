> 本篇知识点（拟）：同一格光路共享一张偏向角地形、各有各的窗口；「地形层」的特征（极值、鞍点）只由面的朝向决定，「窗口层」的特征由面的大小（截面）决定；内部全反射起始线是朝向决定的，所以 Liljequist 峰的**位置**不动，峰的**形状**跟着窗口走。

## 提纲

**本篇回答的问题：Liljequist 幻日那个窄峰，为什么对晶体截面形状那么敏感？** 一句话答案：142° 锐边是**地形**上的点（A60-10 的鞍点），截面只改它的亮度、不改它的位置和形状；Liljequist 窄峰的**位置**也是朝向决定的（晶体内部开始全反射的那条线），但它的**形状**——窄峰还是平台——由这一格里各条光路的**窗口**加起来决定，而窗口正是截面形状直接改动的东西。§1 摆现象（ch8 图 7 重读），§2 位置为什么不动，§3 形状由窗口定（先看 $h/a$，再看截面），§4 与 142° 边对照，§5 文献与太阳高度，§6 留局面。

口径（全篇统一，附录说明）：本仓数字全部是 ch8 图 7 的 Lumice 过滤渲染（片晶 $h/a=0.2$、zenith σ = 0.5°、太阳 0°、幻日环条带 ±1.5°、0.5° 桶，**整格**而非单条光路）；LI 数字是单条光路、随机取向下的偏向角剖面（太阳 0° 时幻日环方位角 = 到太阳的角距，两者可以并排，但不逐数比对）。

### 1. 重读图 7：峰没有挪，是外侧被填平了

- 这节回答的问题：「窄峰摊平」到底是什么变了？是峰移走了、变宽了，还是别的？
- 锚定实例：ch8 图 7 右栏（幻日环那一格，A0-02）的四条剖面。
- 具体结果（`code/check_liljequist_sensitivity.py` [2]、[3]）：
  - ch8 表里「幻日环格峰」一列 153.8° → 177.8° → 178.8° → 153.8°，看起来峰跑到了反日点——其实是平台上的涨落把 argmax 拉走了，不是峰移动。
  - 看剖面**形状**：四档 $d$ 的最陡上升都在同一对桶之间（152.75° → 153.25°，中点 153.00°）；变的是外侧——$d=1$ 时是下降的尾巴（170–180° 均值 / 153–154.5° 均值 = 0.065），$d\ge1.2$ 变成一路铺到反日点的平台（该比值 1.30 / 2.00 / 0.96）。
  - 所以 ch8 说的「摊平」准确地说是：**内侧陡升不动，外侧被填平**。半高全宽 6.42° → 27.15°（×4.23），之后在 26.0–28.3° 之间波动；整格条带能量 37.8 → 74.9 → 97.8 → 41.6，先升后降（最大在 $d=1.4$，是 $d=1$ 的 2.59 倍），不是单调衰减。
- 数据出处：`08-wedge-times-fold/data/cross_section_sensitivity.csv`、`cross_section_sensitivity_summary.csv`（ch8 `code/fig_cross_section_sensitivity.py` 产出）；本章 `code/check_liljequist_sensitivity.py` [2]、[3]。
- 图占位：图 2（图表，核心）——ch8 图 7 右栏重画为线性纵轴、横轴 145–180°，153° 处画竖线，标「陡升不动」「外侧：尾巴 → 平台」；可叠 $d=1$ 与 $d=1.2$ 两条即可。

### 2. 位置：153° 由朝向决定

- 这节回答的问题：为什么那道陡升（Liljequist 峰的内侧）在截面变化下纹丝不动？
- 锚定实例：`3-5-6-7-3`——从侧面 3 进，在 5、6、7 上依次反射，从 3 出（ch8 §6）。它与幻日环主光路 `1-3-2` 同一个 $\Phi$、同一张偏向角地形。
- 具体结果（LI 转录，脚本 [5]）：
  - 地形：`1-3-2` 与 `3-5-6-7-3` 是同一个场 $D_P=2\arcsin\lvert\mathbf u\cdot\mathbf n_3\rvert$（两者差到 8.9e-16 rad），$\lvert\nabla D_P\rvert\equiv2$——一块匀速的坡，没有碗底、没有马鞍，与 $h/a$ 无关。
  - 峰：153.069685° 是面 5、6、7 内部开始全反射那条线上 $D_P$ 的最大值（三面一致到 5e-11°）。越过这条线，某次内反射从「全反射」变成「部分反射」，亮度剖面在这里连续、但折一个角（ch12 §5 已给「不是临界值」一句，这里只接着用）。
  - 为什么不动：全反射起始只看光线打在面上的入射角，入射角只由面的**朝向**决定；三档 $h/a$（0.2 / 1 / 2）峰位都在 153.0697°（0.05° 网格读数 153.10°）。截面变形 $[1,d,1,d,1,d]$ 只把偶数面推远、不改朝向，所以同一论证照样成立 [推]；LI 探针在 $d=1$ 与 $d=1.2$ 下 `focusing.classify` 的临界值逐位相同（浮点噪声 < 1e-13°），是地形不变的直接证据（探针量级）。
  - 本仓对照：ch8 整格剖面的最陡上升 153.00°（§1）与 LI 153.07° 落在同一个 0.5° 桶——口径不同（整格 vs 单条、片晶 vs 随机），只并排、不互证。LI 另有一次 ch8 场景的对照（未过滤的 Lumice，153.75° 桶内的最大值两边一致），引 LI 附录。
- 数据出处：LI `docs/phase2.md` §4 同名条（场、$\lvert\nabla D_P\rvert$、TIR 起始线）、附录「Chapter-10 verdicts rerun」（153.069685°、三面一致、折角斜率、Lumice 对照）；LI `src/lumice_integral/ch10_verdicts.py`（`liljequist`、`tir_onset_maximum`）；LI 探针 `explore-ch12-anchor-probes/experiments.md` #2；本章脚本 [3]。
- 图占位：图 3（A 类示意）——$\mathbf u$ 球上一片匀速坡（等值线平行），上面叠一条「面 6 开始全反射」的曲线；曲线上 $D_P$ 最高的那一点标 153.07°。旁边小图：亮度剖面在该点折角。

### 3. 形状：窗口说了算

- 这节回答的问题：位置不动，那窄峰的宽度、高度、外侧是尾巴还是平台，由什么决定？截面怎么够得着它？
- 锚定实例：先看 LI 已测的 $h/a$ 方向（正六边形截面），再看 ch8 图 7 的截面方向。
- 具体结果：
  - **$h/a$ 方向**（LI 转录，脚本 [4]）：`3-5-6-7-3` 单条随机取向剖面的半高区间 152.55–158.80°、149.80–157.30°、147.65–157.05°（$h/a$ = 0.2 / 1 / 2），宽 6.25° → 7.50° → 9.40°；峰位三档都在 153.07°。地形不变，变的只有这条光路在 $\mathbf u$ 球上能走通的那片区域（窗口）和每个 $\mathbf u$ 上的权重——宽窄就是窗口的样子。
  - **截面方向**：截面改的正是窗口（面的大小决定哪些入射点能走完整条路）。LI 探针的 `geometry.entry_measure`（`3-5-6-7-3` 的入射测度）$d=1\to1.2$ 从 0.0149 降到 0.0060（×0.40，探针量级）——面 6 是被推远、变小的偶数面，这条光路自己**变暗**了。
  - **同一格，谁在铺平台** [推]：可 ch8 整格能量同一步 ×1.98（脚本 [4]）——方向相反。说明 $d\ge1.2$ 那片到反日点的平台多半不是 `3-5-6-7-3` 自己撑起来的，而是同一格（同一个 $\Phi$，因而同一张地形）里别的成员，截面一变它们的窗口打开了。同一张地形、不同的窗口，加起来就是这一格的剖面；正六边形下恰好只有 `3-5-6-7-3` 的窗口集中在 153–159° 那一小段，才有「窄峰」。这一步目前只有方向证据（口径不同：探针是全体可行 $\mathbf u$，ch8 是片晶、太阳 0°），**逐成员分解是动笔前置第 1、2 条**。
  - 回收 ch8 的一句伏笔：ch8 图 5 说「不同面之间互相遮挡，几何效应对晕亮度的影响了，后文我们还会看到」——就是这里。
- 数据出处：LI `docs/phase2.md` 附录「Chapter-10 verdicts rerun」（半高区间）；LI 探针 `explore-ch12-anchor-probes/experiments.md` #2、`SUMMARY.md` 能力矩阵（entry_measure）；本章脚本 [2]、[4]；ch8 第 251–253 行（图 5 伏笔）。
- 图占位：图 4（A 类示意，核心）——同一张地形上画两三块窗口（`3-5-6-7-3` 一块 + 同格别的成员），$d=1$ 与 $d=1.2$ 两栏并排：`3-5-6-7-3` 的窗口缩小、别的窗口伸展到高 $D$ 一侧；下方各自的剖面加和。**内容取决于动笔前置 1、2 的结果**，若分解结论不同，此图重画。

### 4. 对照：142° 边为什么不敏感

- 这节回答的问题：同样是截面变形，为什么 142° 锐边只是变暗？
- 锚定实例：A60-10（`3-5-6-7` / `3-4-5-7`，60° 楔 + 120° 折叠），ch8 图 7 左栏。
- 具体结果：
  - 量化（脚本 [1]）：锐边（内侧半高点）142.56° / 142.21° / 142.04° / 141.55°，四档 $d$ 极差 1.01°（0.5° 桶）；条带能量 25.48 → 16.22 → 7.70 → 1.15（单调降，$d=1.8$ 时剩 0.045 倍）。与 §1 的 A0-02（半高全宽 ×4.23、能量先升后降）并排。
  - 机制：142° 边是地形上的鞍点，$120°+D_{\min}(\texttt{3-5})=141.83929991°$（LI 实测；本仓闭式 $120°+D_{\min}(60°, n=1.31)$ 与之差 −2.3e-10°，脚本 [4]），位置由地形定，窗口只给它乘一个权重——所以截面变形让它变暗而不挪。Liljequist 峰的**位置**同样由朝向定（§2），但它的**形状**本来就是窗口画出来的——截面动的恰好是这一层。
  - 一句话收束：**锐边属于地形，窄峰的样子属于窗口；截面形状只碰得到窗口。**
  - 与 ch12 的分界：ch12 §5 讲「142° 边是鞍点、Liljequist 不是临界值」这层**分类**；本节只讲分类的**后果**——为什么一个经得起截面变形、一个经不起。不重讲临界点。
- 数据出处：本章脚本 [1]、[4]；LI `docs/phase2.md` 附录「Chapter-10 verdicts rerun」（141.83929991°，$h/a$ 三档极差 2.8e-14°）；8.1 番外第 163 行（141.84° 的古典推导）。
- 图占位：图 5（图表）——两格的「形状指标 vs $d$」小多图：左 A60-10 锐边位置（平）与能量（降），右 A0-02 陡升位置（平）与外侧平台比（0.065 → ~1–2）。数据全部来自本章脚本。

### 5. 文献与太阳高度（短节，按动笔前置 3 的结果定取舍）

- 这节回答的问题：观测上的 Liljequist 幻日在哪、会不会动？和本篇「位置不动」怎么对上？
- 锚定实例：ch8 第 279 行引的文献说法——太阳贴地平线时约 160°，太阳升到 30° 左右移到约 150°。
- 具体结果：
  - 本篇的「不动」是**对 $h/a$ 和截面**不动；太阳高度是另一个变量——太阳离开地平线后，幻日环方位角不再等于到太阳的角距，峰在环上的方位自然会变。这一段只给定性说法。
  - 数值上的出入：文献「太阳 0° 时约 160°」与 LI / Lumice 的 153–154° 差了约 6°。本篇**不裁定**原因（文献口径、截面、折射率都可能），列为动笔前置 3。
- 数据出处：ch8 第 279 行与参考资料（Wikipedia: Liljequist parhelion）；原始文献（Liljequist 1956 南极观测报告）尚未查核。
- 图占位：无（或并入图 1 图题一句）。

### 6. 尾声：留局面

写法沿 ch7–ch12：不写「下一篇会讲」，只把局面摆出来。

- ch12 留下的那句「为什么 Liljequist 峰对截面形状那么敏感」有了答案：位置在地形上，形状在窗口里，截面只碰窗口。
- 反过来看：窗口层对截面这么敏感，Liljequist 窄峰就成了截面形状的一个**探针**——看到窄峰，说明晶体截面相当接近正六边形；看到平台，说明偏了。这是「从天空倒推冰晶」的一个具体例子（不展开，留局面）。
- 仍然没回答的：窗口层对别的形状参数（非交替截面、法向本身偏转）怎么反应——LI 目前算不了（见动笔前置 4），本仓 Lumice 可以渲染但没有机制解释。

1. **单光路 `3-5-6-7-3` 的截面剖面**（LI 侧，即 LI 探针 SUMMARY 建议的 explore `ch08-liljequist-numeric-reproduction`，尚未执行）：在 $d\in\{1,1.2,1.4,1.8\}$ 下，对齐 ch8 口径（片晶 $h/a=0.2$、zenith σ = 0.5°、太阳 0°、条带 ±1.5°、0.5° 桶），给出 `3-5-6-7-3` 单条的峰位、峰高、半高全宽，以及 153° 外侧是尾巴还是平台。预期（待验证）：峰位不动、峰高随 $d$ 下降、外侧仍是尾巴。可行性：只挪距离不改朝向的截面在 LI 单光路层可算（`optics` 读的是理想法向，恰与真值一致；`geometry.entry_measure` 读真实几何），但**全图渲染 / 对称搬运只支持 `HexPrism`**，需要在单光路层手工求和。
